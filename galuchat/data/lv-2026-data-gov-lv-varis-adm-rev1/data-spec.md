# ラトビア住所登録行政区域（2026年）

## 1. 概要

国家土地局（VZD）の住所登録空間データを基に、Novadsと市・Pagastsの行政区域を参照できる区域図・名称辞書を収録する。地図は重複しない末端区域を表し、非ゼロ値は同梱GisWordBookのコードである。原典コードとの対応はnames.csvで確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | ラトビア住所登録行政区域（2026年） |
| リリースパッケージID | `lv-2026-data-gov-lv-varis-adm` |
| 対象地域 | 採用原典の市・Pagastsが表すラトビア全域。 |
| 対象区域 | Pagastiの511区域とPilsetasの82市、計593末端区域。上位はNovadiの35区域と国に直接所属する7市、計42区域。 |
| 入力座標系 | LKS-92 / Latvia TM（EPSG:3059）。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | EPSG:3059からEPSG:4326へ再投影・測地系変換する。 |
| 原典版・基準時点 | 日次更新のAW_SHP.zip。採用原典のZIPメンバー時刻とDBF更新日は2026-09-29。2026-01-01基準の行政界ではない。 |

### 1.1 対象範囲

PagastiおよびPilsetasの全区域を末端区域として採用する。Novadiは親の名称・コードを提供し、その面を子の上に別コードで重ねない。Adm_robは同じ親子区域を混在して収録しているため、独立した地図区域として追加しない。

Novadsに所属する市・Pagastsは、VKUR_CDとVKUR_TIPSに従って上位へ対応付ける。国コード100000000に直接所属する市は、その市自身を区域1に置き、区域2を空文字とする。Rīga、Daugavpils、Jelgava、Jūrmala、Liepāja、Rēzekne、Ventspilsがこれに該当する。

Ciemi・Mazciemi・住所点・街路・道路は地図の末端区域に含めない。島状の部分、飛地、穴と隣国との境界は原典に従い、別の国境資料による補正を行わない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `SIMPLE` | 原典の行政区域の海岸側外縁を簡略な水際線として扱い、その外側の海域を除外した区域図とする。海岸線の詳細実測精度を保証するものではなく、追加の海岸線資料は使用しない。 |
| 内水面 | `NONE` | 湖沼・河川を一律に除外せず、原典の市・Pagastsに含まれる水面はその区域として保持する。陸域と水面を識別する値は持たず、原典図形の穴は背景となる。 |

### 1.3 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | 末端となるPagastiまたはPilsetasのKODS。9桁の住所登録対象コード。ATRIBのATVK分類コードとは別。 |
| 原典ID値 | remap前のGisRaster値は末端区域のKODSを10進整数にした正の値。採用した593区域で一意。 |
| 背景値 | `0`。末端区域の外側、原典図形の穴、サンプリングで区域が選ばれなかった画素。水域専用の値ではない。 |
| GisWordBookコード | 原典ID値の昇順で、1から593まで採番する。0は辞書レコードを指さない。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書の葉レコードとnames.csvのwordbook_codeに対応する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 各地点の末端区域をGisWordBookコードで表す。背景は0。 |
| GisWordBook | [所属自治体名, 市またはPagasts名]の固定2スロット。独立市では区域1が末端となり、区域2の空文字を保持する。 UTF-8版とUTF-16LE版は同一のコード空間・レコード順序を持つ。 |
| names.csv | `wordbook_code,GRVALUE,PARENT_CODE,PARENT_NAME,AREA_CODE,AREA_NAME,TIPS_CD,ATVK_CODE`の8列。ヘッダーを除くデータ行は末端区域ごとに1行、計593行。 |

GRVALUEは末端区域の原典ID値。AREA_CODE・AREA_NAMEは末端区域のKODS・NOSAUKUMS、TIPS_CDは末端区域の種類、ATVK_CODEはATRIBの文字列であり先頭ゼロを保持する。PARENT_CODE・PARENT_NAMEはNovadsに属する場合にそのKODS・NOSAUKUMSを記録し、国に直接属する独立市では空文字とする。国コードを架空の自治体として名称階層へ追加しない。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | 所属Novads名。独立市ではその市の名称。 | 不可 |
| 区域2 | Novadsに所属する市またはPagastsの名称。独立市では空文字。 | 空文字可（スロットは固定） |

国名等の共通ノードと属性スロットは含めない。区域1・区域2の組で辞書レコードを識別する。採用593区域ではこの組がすべて一意であり、同名別区域の名称集約は生じない。種類と原典コードはnames.csvに保持する。同じ末端区域の複数の図形部分には同じ辞書コードを割り当てる。

## 5. 備考・既知の制約

* 独立市の区域2の空文字は欠落した名称ではなく、その市自身が末端であることを示す。
* 村の区域を採用していないため、村名や住所の照合には利用できない。住所登録コードとATVK分類コードを混同しない。
* 区域図は原典の区域を格子化したものであり、境界付近では元のベクトル境界と判定が一致しない場合がある。小島・細い区域・飛地は粗い格子で画素化されない場合がある。
* 背景値0だけから水域や外国を判定できない。区域に含まれる水面は専用コードで区別しない。
* GisWordBookコードは本版の辞書レコードを参照する値であり、異なる版の恒久的な区域IDとして使用しない。照合にはnames.csvに保持した原典コードを用いる。
* 原典名称の文字を保持するためCP932版の辞書は収録しない。名称・区域は採用した原典版に依存し、その後の変更は反映しない。本区域図は法的な境界位置や土地の権利を確定するものではない。
