# チェコRÚIAN自治体区域（2026年）

## 1. 概要

ČÚZKのRÚIANを基に、広域自治体（VÚSC）、郡相当区域（Okres）、自治体相当区域（Obec）を参照できる区域図・名称辞書を収録する。軍事区域も末端区域として含める。区域図の非ゼロ値は同梱GisWordBookのコードであり、原典コードとの対応はnames.csvで確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | チェコRÚIAN自治体区域（2026年） |
| リリースパッケージID | `cz-2026-cuzk-gov-cz-ruian-adm` |
| 対象地域 | 原典のOBCE_Pが表すチェコ全域。軍事区域、島状の部分および飛地を含む。 |
| 対象区域 | OBCE_Pの6,258区域（通常の自治体6,254件と軍事区域4件）。上位名称はVUSC_Pの14区域とOKRESY_Pの77区域。 |
| 入力座標系 | S-JTSK / Krovak East North（EPSG:5514）。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | EPSG:5514からEPSG:4326へ再投影・測地系変換する。 |
| 原典版・基準時点 | RÚIAN国別SHP、保存済みAtomの更新時刻2026-09-27T20:32:18+02:00に対応する原典。これは2026-01-01基準の行政界ではない。 |

### 1.1 対象範囲

原典のOBCE_P全区域を採用する。軍事区域はSTATUS_KOD=1で区別され、自治体と同様に地図の末端区域として保持する。区域1・区域2の名称は、それぞれVUSC_KOD・OKRES_KODで対応する親レイヤーから取得する。上位区域の面を別の画素値として重ねない。

KATUZE、ZSJ、ORP、POU、選挙区画、建築行政管区および地籍事務所管区は名称階層と区域地図に含めない。名称は原典のチェコ語表記を保持する。飛地・複数の図形部分・穴と隣国との境界は原典に従い、別の国境資料による補正を行わない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `NONE` | 外水面を専用に分離・除外しない。対象は海洋に接しないチェコの原典区域であり、国境による外縁を海岸線クリップとは扱わない。 |
| 内水面 | `NONE` | 湖沼・河川を一律に除外せず、原典の自治体相当区域に含まれる水面はその区域として保持する。区域内の陸域と水面を識別する値は持たず、原典図形の穴は背景となる。 |

### 1.3 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | OBCE_PのKOD。原典のコード文字列を保持する。 |
| 原典ID値 | remap前のGisRaster値はKODを10進整数にした正の値。採用区域で一意。 |
| 背景値 | `0`。末端区域の外側、原典図形の穴、サンプリングで区域が選ばれなかった画素。水域専用の値ではない。 |
| GisWordBookコード | 原典ID値の昇順で、1から6,258まで採番する。区域名称が同じでも属性1のKODが異なるものは別レコード。0は辞書レコードを指さない。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書の葉レコードとnames.csvのwordbook_codeに対応する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 各地点の末端区域をGisWordBookコードで表す。背景は0。 |
| GisWordBook | [VÚSC名, Okres名, Obec名, KOD]の固定4スロット。先頭3スロットが区域階層、最後が末端区域の属性。 UTF-8版とUTF-16LE版は同一のコード空間・レコード順序を持つ。 |
| names.csv | `wordbook_code,GRVALUE,VUSC_CODE,VUSC_NAME,OKRES_CODE,OKRES_NAME,OBEC_CODE,OBEC_NAME,STATUS_KOD`の9列。ヘッダーを除くデータ行は末端区域ごとに1行、計6,258行。 |

GRVALUEは原典ID値。VUSC_CODE・OKRES_CODE・OBEC_CODEは対応する原典KODであり、文字列として収録する。STATUS_KODは末端区域の種類を表す原典値。名称は各レイヤーのNAZEVの表記を保持する。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | VÚSC（広域自治体）の名称。 | 不可 |
| 区域2 | Okres（郡相当区域）の名称。 | 不可 |
| 区域3 | Obecの名称。軍事区域もここに記録する。 | 不可 |
| 属性1 | 末端区域の原典KOD。 | 不可 |

国名等の共通ノードは含めない。区域1・区域2・区域3と属性1の組で辞書レコードを識別する。同じ全名称パスを持つ別コードの区域は、名称を改変せずKODで区別する。同じKODの飛地・複数の図形部分には同じ辞書コードを割り当てる。

## 5. 備考・既知の制約

* MezholezyとBřezinaには、上位名称を含む全名称パスが同じでKODが異なる区域がある。名称だけで集約せず、全件共通の属性1で識別する。
* 原典の軍事区域は通常の自治体とは制度上の種類が異なるが、同じ末端の区域スロットへ収録する。
* 区域図は原典の区域を格子化したものであり、境界付近では元のベクトル境界と判定が一致しない場合がある。小島・細い区域・飛地は粗い格子で画素化されない場合がある。
* 背景値0だけから水域や外国を判定できない。区域に含まれる水面は専用コードで区別しない。
* GisWordBookコードは本版の辞書レコードを参照する値であり、異なる版の恒久的な区域IDとして使用しない。照合にはnames.csvに保持した原典コードを用いる。
* 原典名称の文字を保持するためCP932版の辞書は収録しない。名称・区域は採用した原典版に依存し、その後の変更は反映しない。本区域図は法的な境界位置や土地の権利を確定するものではない。
