# e-Stat海岸線反映区域データ

この文書は本リリースのデータの**外部仕様**を記述する。製造工程や中間ファイル名は規定しない。出典・利用条件は[NOTICE.md](NOTICE.md)を参照する。

## 1. 概要

本データセットは、令和2年国勢調査の町丁・字等境界データに、N03-2026の行政区域が示す海岸線を反映した区域地図である。

| 項目 | 内容 |
| --- | --- |
| データセット名 | e-Stat海岸線反映区域データ |
| リリースパッケージID | `jp-2026-nyatla-jp-estat-coastline` |
| 対象地域 | 日本全国 |
| 対象区域 | e-Statの小地区またはN03の行政区域代表値。採用範囲は第1.3節に従う。 |
| 入力座標系 | N03・e-StatともJGD2011地理座標（EPSG:6668） |
| 出力座標系 | WGS 84互換の緯度経度格子 |
| 座標変換 | 入力のJGD2011座標値を再投影・測地系変換せず、WGS 84互換の座標値として格納する。 |
| 原典版・基準時点 | N03 `N03-20260101`（2026年1月1日時点）、e-Stat `A002005212020`（2020年国勢調査） |

### 1.1 対象範囲

e-Statの町丁・字等を小地区として採用し、N03区域内で採用するe-Stat小地区がない部分はN03の行政区域代表値で表す。指定外水面区域の採用条件は第1.2節、地理的な収録範囲と値の優先関係は第1.3節に定める。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `CUSTOM` | e-Stat原典に含まれる外水面の指定区域は小地区として採用しない。N03の行政区域ラスタの範囲で海岸線を反映し、指定区域の除外だけを理由に全面を背景へ置き換えるものではない。 |
| 内水面 | `NONE` | 水面だけを対象とする追加の切り抜きは行わない。N03の区域判定とe-Statの小地区値に従う。 |

### 1.3 領域・境界

日本全国の47都道府県を対象とし、最終的な地図範囲はN03-2026の行政区域ラスタに従う。島嶼・飛地はN03の収録範囲に含まれる限り対象となる。

| 項目 | 扱い | データとしての意味・備考 |
| --- | --- | --- |
| 国境側の境界 | 該当なし | 収録対象に隣接する国・地域との陸上の国境区間はない。海岸側の扱いは第1.2節に従う。 |
| 対象領域外 | 背景値 | N03の行政区域ラスタで背景となる地点。e-Statに区域値があっても採用しない。 |
| 対象領域内の未割当地点 | 背景値 | N03側の穴・未割当地点やサンプリングで区域が選ばれなかった地点。N03区域内でe-Statの採用値がないことだけでは背景にならない。 |

背景値だけから水域と領域外・内部の未割当地点を区別できない。区域コードは統合辞書の項目を指し、N03の行政区域代表値も陸域専用の値ではない。

N03とe-Statを同じ統合GisWordBookコード空間で解釈した場合の採用関係は次のとおり。e-Statの「値あり」は、第1.2節で採用しないとした指定外水面区域を除いた値を指す。

| N03 | e-Stat | 最終画素値 |
| --- | --- | --- |
| 背景値 | 任意 | 背景値 |
| 区域値あり | 値なし | N03の行政区域代表値 |
| 区域値あり | 値あり | e-Statの小地区値 |

格子化により境界のずれや背景画素が生じ得る。区域図の境目を正確な国境線・原典のベクトル境界として使用しない。

### 1.4 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | e-Statの`PREF,CITY,S_AREA`による地区コードと、N03の`N03_007`による行政区域コード。地区コードは個別ポリゴンの一意IDではない。 |
| 原典ID値 | 各原典の区域コードを数値化した値。最終地図には直接格納しない。 |
| 背景値 | `0`。区域コードが割り当てられていない地点を表し、辞書レコードを指さない。対象領域と背景になる条件は第1.3節を参照。 |
| GisWordBookコード | 統合GisWordBookの葉レコードを新規採番した`x_district_id2 + 1`。 |
| マップコード | 最終WGSMapSetの非0画素値。対応する統合GisWordBookの葉レコードを指す。 |

同名・同一地区コードの複数ポリゴンがあり得る。マップコードは名称階層の項目を指し、個別ポリゴンを識別するものではない。

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 第1.3節の対象領域に属するe-Stat小地区またはN03行政区域代表値を、統合GisWordBookコードで表す。 |
| GisWordBook | N03の行政階層とe-Statの小地区階層を統合した固定6階層の名称辞書。3種類の文字コード版はレコード順序、コードおよび論理内容が同一である。 |

### 3.2 StringSet

GisWordBookの各レコードは次の6スロットの固定長パスを持つ。国名などの共通ノードは含めない。

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | 都道府県 | 不可 |
| 区域2 | 郡 | 可。存在しない場合は空文字列。 |
| 区域3 | 市区町村 | 不可 |
| 区域4 | 政令指定都市の行政区 | 可。存在しない場合は空文字列。 |
| 区域5 | e-Stat小地区 | 可。行政区域代表値では空文字列。 |
| 区域6 | e-Stat下位地区 | 可。存在しない場合は空文字列。 |

区域5・6がともに空文字列の項目はN03の行政区域代表値である。e-Statの小地区はN03の行政階層の下に配置する。同じ表示名が複数あっても、全階層の組合せとコードで区別する。

## 4. WGSMapSet生成パラメータ

### gis-estat-integrated-grid-8192-10000.wgsmapset.glc

#### サンプリング方式

| 項目 | 値 | 備考 |
| --- | --- | --- |
| sampling | `MAX_AREA` | e-Stat区域のセル内最大面積を採用する。N03側の値は上流N03パッケージの仕様に従う。 |
| minimum rate | `0.01` | e-Stat区域の最小採用率。 |

#### WGSMapSet格納方式

| 項目 | 値 | 備考 |
| --- | --- | --- |
| palette / block format / 圧縮 | `auto` / `all` / `lzss` | 最終WGSMapの格納設定。 |
| unit-inv | `10000` | サンプリング単位は1/10000度。 |
| SHP grid cell-size | `8192` | 対応するShapefile分割格子のセルサイズ。 |
| block-size | `512` | WGSMapSetブロックサイズ。 |

## 5. 備考・既知の制約

- e-Statの町丁・字等境界は統計調査用で、一般的な行政区域や住居表示の境界と必ずしも一致しない。N03とe-Statの基準時点も異なる。
