# オーストリア自治体・ウィーン市区（2026-01-01）

## 1. 概要

Statistik AustriaのGemeinden 2026-01-01を基に、州と自治体・ウィーン市区を参照できる区域図・名称辞書を収録する。原典はウィーンを23市区に分けて収録しており、その粒度を保持する。非ゼロの画素値は同梱GisWordBookのコードであり、原典コードとの対応はnames.csvで確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | オーストリア自治体・ウィーン市区（2026-01-01） |
| リリースパッケージID | `at-2026-data-statistik-gv-at-gem-adm` |
| 対象地域 | 原典GEMレイヤーが表すオーストリア全域。ウィーンは原典の23市区。 |
| 対象区域 | ウィーン以外の2,091自治体とウィーンの23市区、計2,114末端区域。上位名称階層には9州を使用する。 |
| 入力座標系 | MGI / Austria Lambert（EPSG:31287）。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | EPSG:31287からEPSG:4326へ再投影・測地系変換する。MGIとWGS 84は異なる測地系であり、座標系ラベルの付替えではない。 |
| 原典版・基準時点 | STATISTIK_AUSTRIA_GEM_20260101、基準日2026-01-01。 |

### 1.1 対象範囲

原典の2,114区域を採用する。ウィーンの23市区を1市へ統合せず、別の末端区域として保持する。名称階層は州→原典末端区域の2段階とし、政治郡・司法郡は収録しない。

州はg_idの先頭1桁に対応する。州コード1～9に対してそれぞれBurgenland、Kärnten、Niederösterreich、Oberösterreich、Salzburg、Steiermark、Tirol、Vorarlberg、Wienの公式表記を使用する。末端名称はg_nameの表記を保持し、Wien-で始まる原典市区名も変更しない。

飛地、島状の部分、複数の図形部分、穴および隣国との境界は原典に従い、別の国境資料による補正を行わない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `NONE` | 外水面を専用に分離・除外しない。対象は海洋に接しないオーストリアの原典区域であり、国境による外縁を海岸線クリップとは扱わない。 |
| 内水面 | `NONE` | 湖沼・河川を一律に除外せず、原典の自治体・市区に含まれる水面はその区域として保持する。水面を明示する値は持たず、原典図形の穴は背景となる。 |

### 1.3 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | 原典GEMレイヤーのg_id。5桁の区域コード文字列。ウィーン市区にも別々のg_idがある。 |
| 原典ID値 | remap前のGisRaster値はg_idを10進整数にした正の値。採用2,114区域で一意。 |
| 背景値 | `0`。末端区域の外側、原典図形の穴、サンプリングで区域が選ばれなかった画素。水域専用の値ではない。 |
| GisWordBookコード | 原典ID値の昇順で、1から2,114まで採番する。0は辞書レコードを指さない。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書の葉レコードとnames.csvのwordbook_codeに対応する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 各地点の末端区域をGisWordBookコードで表す。背景は0。 |
| GisWordBook | [Bundesland名, g_name]の固定2スロット。末端は自治体またはウィーン市区。 UTF-8版とUTF-16LE版は同一のコード空間・レコード順序を持つ。 |
| names.csv | `wordbook_code,GRVALUE,BUNDESLAND_CODE,BUNDESLAND_NAME,AREA_CODE,AREA_NAME,AREA_TYPE`の7列。ヘッダーを除くデータ行は末端区域ごとに1行、計2,114行。 |

GRVALUEは原典ID値。AREA_CODE・AREA_NAMEはg_id・g_nameに対応する。BUNDESLAND_CODEはg_idの先頭1桁、BUNDESLAND_NAMEは対応する州の公式名称。AREA_TYPEはウィーン市区をVIENNA_DISTRICT、それ以外をMUNICIPALITYと記録する。AREA_CODEは5桁の文字列として保持する。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | Bundesland（州）の名称。 | 不可 |
| 区域2 | 原典の自治体またはウィーン市区の名称（g_name）。 | 不可 |

国名等の共通ノード、政治郡、司法郡および属性スロットは含めない。区域1・区域2の組で辞書レコードを識別する。採用2,114区域ではこの組がすべて一意であり、別区域の名称集約は生じない。末端種類と原典コードはnames.csvに保持する。同じg_idの複数の図形部分には同じ辞書コードを割り当てる。

## 5. 備考・既知の制約

* 原典レコード2,114件は自治体2,114件を意味しない。ウィーンを1自治体として数える公式の自治体数2,092件とは、ウィーンの末端粒度が異なる。
* g_idの先頭3桁をすべて政治郡コードと解釈しない。特にウィーン市区のコードを別々の政治郡と扱わない。
* 区域図は原典の区域を格子化したものであり、境界付近では元のベクトル境界と判定が一致しない場合がある。小島・細い区域・飛地は粗い格子で画素化されない場合がある。
* 背景値0だけから水域や外国を判定できない。区域に含まれる水面は専用コードで区別しない。
* GisWordBookコードは本版の辞書レコードを参照する値であり、異なる版の恒久的な区域IDとして使用しない。照合にはnames.csvに保持した原典コードを用いる。
* 原典名称の文字を保持するためCP932版の辞書は収録しない。名称・区域は採用した原典版に依存し、その後の変更は反映しない。本区域図は法的な境界位置や土地の権利を確定するものではない。
