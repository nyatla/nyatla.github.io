# スロバキアZBGIS自治体区域（2026年版）

## 1. 概要

GKÚ BratislavaのZBGIS行政界を基に、地域（Kraj）、郡（Okres）、自治体等（Obec）の3段階を参照できる区域図・名称辞書を収録する。末端区域には原典の都市内区域と軍事区域も含める。区域図の非ゼロ値は同梱GisWordBookのコードであり、原典コードとの対応はnames.csvで確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | スロバキアZBGIS自治体区域（2026年版） |
| リリースパッケージID | `sk-2026-skgeodesy-sk-zbgis-adm` |
| 対象地域 | 原典のobec_0面が表すスロバキア全域。軍事区域、島状部分、飛地および原典区域に含まれる水面を含む。 |
| 対象区域 | Obecレベルの2,927区域。上位名称は8のKrajと79のOkres。 |
| 入力座標系 | S-JTSK / Krovak East North（EPSG:5514）の水平座標。原典PRJはBaltic 1957 height（EPSG:8357）を併記した複合CRS。S-JTSK[JTSK03]（EPSG:8353）の別製品ではない。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | 地図には原典CRSの水平成分を使用し、EPSG:5514からEPSG:4326へ再投影・測地系変換する。高さを持たない2D区域図に鉛直変換は適用しない。 |
| 原典版・基準時点 | ZBGIS行政界の基本レベルah_shp_0.zip。原則2026-06-30時点。ただしNitra、Dunajská Streda、Topoľčany、Čadca、Liptovský Mikuláš、Veľký Krtíš、Michalovce、Trebišovの8郡は2024-12-31時点であり、全国一律の2026年境界ではない。 |

### 1.1 対象範囲

原典のobec_0全区域を末端区域として採用する。区域1はKraj、区域2はOkres、区域3はObecレベルの区域名とし、原典のIDN2・IDN3・IDN4による所属に従う。上位区域の面を別の画素値として重ねない。

Bratislava等の都市内区域は原典のObecレベルの粒度を保持し、市全体へ独自に集約しない。Záhorie、Lešť、Valaškovceのvojenský obvod（軍事区域）も原典名のまま含める。通常の自治体と制度上の種類が異なっても、同じ末端区域スロットに収録する。

obec_0と同一内容のobec_0_1を重複収録しない。地籍区域（ku_0）、国の共通ノードおよび一般化レベルの別製品は収録しない。名称は原典のスロバキア語表記を保持する。

2,927区域は通常の自治体だけを数えた件数ではない。更新日が古い区域も採用原典の一部として保持する。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `NONE` | 外水面を専用に分離・除外しない。対象は海洋に接しないスロバキアの原典区域であり、国境による外縁を海岸線クリップとは扱わない。 |
| 内水面 | `NONE` | 湖沼・河川・貯水池を一律に除外せず、原典のObecレベルの面に含まれる水面はその区域として保持する。水面と陸域を明示的に区別する値は持たず、追加の内水面マスクは適用しない。 |

### 1.3 領域・境界

スロバキアの原典obec_0全区域の収録範囲を対象とし、飛地・全図形部分・穴を原典どおり保持する。

| 項目 | 扱い | データとしての意味・備考 |
| --- | --- | --- |
| 国境側の境界 | 原典準拠 | 採用する原典区域の境界に従い、別の国境資料による補正は行わない。 |
| 対象領域外 | 背景値 | 採用区域面の外側。 |
| 対象領域内の未割当地点 | 背景値 | 採用面に穴・区域間の隙間がある場合の未割当地点、またはサンプリングで区域が選ばれなかった地点。 |

背景値だけでは領域外、水域、内部の未割当地点を区別できない。区域コードも陸域のみを示す値ではなく、水域の扱いは第1.2節に従う。

格子化により境界のずれや背景画素が生じ得る。区域図の境目を正確な国境線・原典のベクトル境界として使用しない。

### 1.4 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | ObecレベルのIDN4。原典のコード文字列をnames.csvに保持する。 |
| 原典ID値 | remap前のGisRaster値はIDN4を10進整数にした正の値。本版の範囲は500,011～599,972で欠番を含む。採用区域で一意であり、国・地域・郡・地籍区域のコードを代用しない。 |
| 背景値 | `0`。区域コードが割り当てられていない地点を表し、辞書レコードを指さない。対象領域と背景になる条件は第1.3節を参照。 |
| GisWordBookコード | 原典ID値の昇順に1から2,927まで採番する。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書の葉レコードとnames.csvのwordbook_codeに対応する。全解像度で同じ辞書コード空間を使用する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 第1.3節の対象領域で、末端区域をGisWordBookコードで表す。 |
| GisWordBook | [地域名, 郡名, 自治体等名]の固定3スロット。すべて区域階層であり、属性スロットは設けない。UTF-8版とUTF-16LE版は同一のコード空間・レコード順序を持つ。 |
| names.csv | `wordbook_code,GRVALUE,KRAJ_CODE,KRAJ_NAME,OKRES_CODE,OKRES_NAME,OBEC_CODE,OBEC_NAME,DOW`の9列。ヘッダーを除くデータ行は末端区域ごとに1行、計2,927行。 |

GRVALUEはIDN4に対応する原典ID値。KRAJ_CODE・OKRES_CODE・OBEC_CODEは、それぞれIDN2・IDN3・IDN4の10進コード文字列。名称はNM2・NM3・NM4の原典表記を保持する。DOWは末端区域の原典更新日をYYYY-MM-DD形式で保持し、全国一律の境界基準日として扱わない。

本版の末端区域のDOWは、2024-12-31が493件、2026-06-30が2,434件である。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | Kraj（地域）の名称NM2。 | 不可 |
| 区域2 | Okres（郡）の名称NM3。 | 不可 |
| 区域3 | Obecレベルの区域の名称NM4。都市内区域・軍事区域を含む。 | 不可 |

国名等の共通ノード、空スロットおよび属性スロットは含めない。辞書レコードは区域1・区域2・区域3の組で識別し、本版の2,927末端区域では異なる原典IDがこの組を共有しない。同じIDN4の飛地・複数の図形部分には同じ辞書コードを割り当てる。

## 5. 備考・既知の制約

- 小島・細い区域・飛地は、粗い格子で画素として選ばれない場合がある。辞書のレコード数は、各解像度で出現する画素値の種類数を保証しない。
- GisWordBookコードは本版の辞書レコードを参照する値であり、異なる版の恒久的な区域IDとして使用しない。原典との照合にはnames.csvの識別子を用いる。
- 原典名称の文字を保持するためCP932版の辞書は収録しない。名称・区域は採用した原典版に依存し、その後の変更は反映しない。本区域図は法的な境界位置や土地の権利を確定するものではない。
