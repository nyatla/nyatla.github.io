# セルビアGeoanalitičari集落区域

## 1. 概要

Geoanalitičariが提供するHypso_Struct_Settlの集落区域を基に、原典の自治体名と集落名を参照できる区域図・名称辞書を収録する。名称階層は各集落レコードの原典表記による「自治体名 → 集落名」であり、現行の自治体コード体系を再現するものではない。標高帯別の統計値は収録しない。

| 項目 | 内容 |
| --- | --- |
| データセット名 | セルビアGeoanalitičari集落区域 |
| リリースパッケージID | `rs-undated-data-gov-rs-hypso-struct-settl-adm` |
| 対象地域 | 原典に収録されたセルビアの集落区域。コソボは原典の収録対象外。 |
| 対象区域 | Naselje（集落）の4,721区域。表示階層は自治体名・集落名の2段階。 |
| 入力座標系 | WGS 84 / UTM zone 34N（EPSG:32634）。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | EPSG:32634からEPSG:4326へ再投影する。 |
| 原典版・基準時点 | 2021-06-18公開のHypso_Struct_Settl配布物。行政界の基準日は未確認。公開日およびDBFの更新日を行政界基準日とは扱わない。 |

`undated`は境界基準年が不詳であることを示し、現行・最新版を意味しない。

### 1.1 対象範囲

原典の集落区域をすべて採用する。Naseljeは市街地や建物の密集範囲だけではなく、それ以外の土地も含む集落の区域である。各集落に記録された自治体名を上位の表示名称とし、自治体の面を別の画素値として重ねない。県・地方等の上位階層と国名の共通ノードは収録しない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `NONE` | 原典の集落面に含まれる水面は集落の区域として保持する。対象地域は内陸にあり、海岸線による除外は適用しない。水域としての分類値は持たない。 |
| 内水面 | `NONE` | 湖沼・河川等を一律に除外せず、原典の集落面に含まれる水面はその集落の区域として保持する。水面と非水面を明示的に区別する属性はなく、標高値から水域を推定しない。 |

### 1.3 領域・境界

セルビアの原典集落区域の収録範囲を対象とし、原典の解説に従いコソボは収録しない。この範囲は採用原典の収録範囲を説明するものであり、政治的な地位や領有を判定するものではない。複数の図形部分・島状部分・飛地・穴を保持し、最大の部分だけの採用や小面積による除外は行わない。

| 項目 | 扱い | データとしての意味・備考 |
| --- | --- | --- |
| 国境側の境界 | 原典準拠 | 採用する原典区域の境界に従い、別の国境資料による補正は行わない。 |
| 対象領域外 | 背景値 | 採用区域面の外側。 |
| 対象領域内の未割当地点 | 背景値 | 採用面に穴・区域間の隙間がある場合の未割当地点、またはサンプリングで区域が選ばれなかった地点。 |

背景値だけでは領域外、水域、内部の未割当地点を区別できない。区域コードも陸域のみを示す値ではなく、水域の扱いは第1.2節に従う。

格子化により境界のずれや背景画素が生じ得る。区域図の境目を正確な国境線・原典のベクトル境界として使用しない。

### 1.4 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | 集落識別コード`MatBrNas`。採用した4,721レコードで一意。自治体コード`MatBrO`との組を集落IDとする必要はない。 |
| 原典ID値 | remap前のGisRaster値は`MatBrNas`の10進整数値。自治体コードや名称から計算した値ではない。 |
| 背景値 | `0`。区域コードが割り当てられていない地点を表し、辞書レコードを指さない。対象領域と背景になる条件は第1.3節を参照。 |
| GisWordBookコード | `MatBrNas`の数値昇順で、1から4,721まで採番する。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書の葉レコードおよびnames.csvのwordbook_codeに対応する。 |

MatBrNasの桁や接頭辞は、自治体所属を表すものとして扱わない。所属との対応はnames.csvの各レコードに従う。

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 第1.3節の対象領域で、集落区域をGisWordBookコードで表す。 |
| GisWordBook | [自治体名, 集落名]の固定2スロット。原典のキリル文字名称を使用する。UTF-8版とUTF-16LE版は同一のコード空間・レコード順序を持つ。 |
| names.csv | `wordbook_code,GRVALUE,MatBrO,MatBrNas,ImeOpsCir,ImeOpsLat,ImeNasCir,ImeNasLat`の8列。ヘッダーを除き集落ごとに1行、計4,721行。 |

GRVALUEは原典ID値であり、MatBrNasの10進整数値と同じ。MatBrOとMatBrNasは原典の識別コードを補正せず保持する。ImeOpsCir・ImeOpsLatは各集落レコードのキリル文字・ラテン文字の自治体名、ImeNasCir・ImeNasLatは同じく集落名である。原典の大文字表記、ダイアクリティカルマークおよび文字体系を保持し、ラテン文字名を独自に生成しない。標高帯の割合と平均標高はこの対応表に含めない。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | 各集落レコードの原典自治体名`ImeOpsCir`。 | 不可 |
| 区域2 | 原典集落名`ImeNasCir`。 | 不可 |

属性スロット、国名等の共通ノード、空スロットは含めない。自治体コードで上位名称を引き直さず、各集落レコードの自治体名を採用する。同じ自治体コードに異なる名称が記録されていても、それぞれの名称を保持する。異なる自治体コードに同じ自治体名が記録されている場合、その名称は同じ表示上の親となるが、集落の識別コードは統合しない。

辞書レコードは[自治体名, 集落名]の組で識別し、本版の4,721集落では異なるMatBrNasがこの組を共有しない。同じMatBrNasの複数の図形部分には同じ辞書コードを割り当てる。

## 5. 備考・既知の制約

- 名称階層は原典レコードの表示上の所属を表し、現行の行政組織・自治体コード体系の完全な再現を保証しない。
- 細い区域・小さな図形部分・飛地は、粗い格子で画素として選ばれない場合がある。
- GisWordBookコードは本版の辞書を参照する値であり、異なる版の恒久的な区域IDとして使用しない。原典との照合にはnames.csvのMatBrNasを用いる。
- キリル文字を含む原典名称を保持するためCP932版の辞書は収録しない。名称・区域は採用原典に依存し、その後の変更は反映しない。本区域図は法的な境界位置や土地の権利を確定するものではない。
