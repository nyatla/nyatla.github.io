# ベルギー統計区 Statistical sectors 2026

## 1. 概要

ベルギー統計局（Statbel / Statistics Belgium）の2026年版統計区を基に、地域、県、行政郡、自治体、統計区の名称を参照できる区域図・名称辞書を収録する。原典の統計区コードを属性として保持し、名称が同じ別の統計区を区別する。区域図の非ゼロ値は同梱GisWordBookのコードであり、原典コードと多言語名称との対応は同梱のnames.csvで確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | ベルギー統計区 Statistical sectors 2026 |
| リリースパッケージID | `be-2026-statbel-fgov-be-statistical-sectors-stat-sector` |
| 対象地域 | 原典の統計区が表すベルギー全域。 |
| 対象区域 | 統計区20,781区域。上位名称には3地域、10県、43行政郡、565自治体を使用する。ブリュッセル首都地域には県の所属がない。 |
| 入力座標系 | ETRS89 / Belgian Lambert 2008（EPSG:3812）。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | EPSG:3812からEPSG:4326へ再投影・測地系変換する。 |
| 原典版・基準時点 | `sh_statbel_statistical_sectors_3812_20260101`。統計区は2026年1月1日基準。同梱説明書は2026年6月8日付。 |

### 1.1 対象範囲

原典の全20,781統計区を採用する。所属先は各統計区レコードの`CNIS_REGIO`（地域）、`CNIS_PROVI`（県）、`CNIS_ARRD_`（行政郡）、`CNIS5_2026`（自治体）に従う。統計区コードの先頭から現在の自治体コードを推定しない。

区域地図の検索対象は統計区であり、上位行政区域を別の画素値として重ねない。地域→県→行政郡→自治体→統計区の固定階層を使用し、ブリュッセル首都地域の749統計区では県のスロットを空文字とする。県を新設したり、地域名を県名として重複させたりしない。

名称辞書は原典のオランダ語名称列（`*_NL`）を使用する。names.csvにはオランダ語・フランス語・ドイツ語の名称列を保持する。名称を翻訳・補作せず、原典の表記を使用する。

飛地、離れた区域部分、内側の穴は原典の形状に従う。同じ統計区コードに属する複数の図形部分は同じ区域コードを持つ。国境は原典準拠とし、別の国境資料による補正は行わない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `NONE` | 原典の統計区図形が覆う範囲は区域として保持し、その範囲に含まれる外水面を陸域と区別する値は収録しない。採用原典に水域を識別する属性がなく、別の海岸線・海域資料によるクリップは行わない。 |
| 内水面 | `NONE` | 統計区に含まれる湖沼・河川等は、その統計区の区域として保持し、内水面専用の値は設けない。採用原典に水域を識別する属性がなく、追加の水域クリップは行わない。原典図形の穴は背景のまま保持する。 |

### 1.3 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | `CS01012026`。英数字およびハイフンから成る9文字の統計区コード。20,781区域で一意であり、文字列のまま保持する。 |
| 原典ID値 | remap前のGisRaster値は、原典IDをASCII辞書順で並べ、1から20,781まで採番した整数値。原典IDそのものの数値変換ではなく、本版内の対応値である。names.csvの`GRVALUE`に収録する。 |
| 背景値 | `0`。統計区図形の外側、原典図形の穴、サンプリングで区域が選ばれなかった画素。水域専用の値ではない。 |
| GisWordBookコード | 原典ID値の昇順で1から20,781まで採番する。各原典IDが1つの辞書レコードに対応し、0は辞書レコードを指さない。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書の葉レコードおよびnames.csvの`wordbook_code`に対応する。本版では原典ID値と辞書コードの数値は一致するが、意味は異なる。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 各地点の統計区をGisWordBookコードで表す。背景は0。 |
| GisWordBook | `[地域名, 県名, 行政郡名, 自治体名, 統計区名, 統計区コード]`の固定6スロット。最初の5スロットが区域階層、最後の1スロットが属性。UTF-8版とUTF-16LE版は同一のコード空間・レコード順序を持つ。 |
| names.csv | 統計区ごとに1行、計20,781行。辞書コード・直接値・原典コードおよび3言語の名称を対応付ける。 |

names.csvの列順は次の22列とする。

`wordbook_code`, `GRVALUE`, `CS01012026`, `CNIS_REGIO`, `T_REGIO_NL`, `T_REGIO_FR`, `T_REGIO_DE`, `CNIS_PROVI`, `T_PROVI_NL`, `T_PROVI_FR`, `T_PROVI_DE`, `CNIS_ARRD_`, `T_ARRD_NL`, `T_ARRD_FR`, `T_ARRD_DE`, `CNIS5_2026`, `T_MUN_NL`, `T_MUN_FR`, `T_MUN_DE`, `T_SEC_NL`, `T_SEC_FR`, `T_SEC_DE`。

`wordbook_code`は辞書コード、`GRVALUE`は原典ID値である。それ以外の列は同名の原典属性に対応する。各所属コードと統計区コードは文字列として先頭ゼロ・文字・ハイフンを保持する。名称のアクセント付き文字、空白、大文字・小文字等の原典表記を保持する。ブリュッセルの県コードおよび3言語の県名は空文字である。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | 地域（Region）の名称。原典の`T_REGIO_NL`。 | 不可 |
| 区域2 | 県（Province）の名称。原典の`T_PROVI_NL`。 | 可（県所属がないブリュッセル首都地域では空文字を保持） |
| 区域3 | 行政郡（Arrondissement）の名称。原典の`T_ARRD_NL`。 | 不可 |
| 区域4 | 自治体（Municipality）の名称。原典の`T_MUN_NL`。 | 不可 |
| 区域5 | 統計区（Statistical sector）の名称。原典の`T_SEC_NL`。 | 不可 |
| 属性1 | 原典統計区コード`CS01012026`。同名別区域を区別する識別属性。 | 不可 |

国名などの共通ノード、原典の6桁・7桁コードによる集約区分、`MUN_DISTR`、他言語名称およびその他の属性はStringSetに含めない。空文字の県スロットを削除せず、常に6スロットとする。

区域1から区域5までの名称パスだけでは同名の別統計区があるため、名称パスと属性1の組で辞書レコードを識別する。全統計区で原典コードを持たせ、別コードの統計区を名称だけで集約しない。同じコードの飛地や複数の図形部分は別の辞書レコードとしない。

## 5. 備考・既知の制約

* 統計区は行政組織そのものではなく、統計集計のための区分である。統計区コードの先頭5文字と現在の自治体コードは一致しない場合がある。所属の解釈にはnames.csvの`CNIS5_2026`を使用する。
* 原典のオランダ語名称パスは20,722組で、名称が同じ別コードの統計区が存在する。本辞書では属性1の統計区コードで区別し、20,781区域を保持する。
* ブリュッセルの県名の空文字は原典上の県所属がないことを示し、名称欠損を補うための仮称ではない。名称階層の途中に空スロットがある。
* オランダ語名称を辞書の表示名とすることは、対象地域の公用語・優先言語を判定したことを意味しない。他言語での表示にはnames.csvの対応列を使用する。
* 同梱説明書は自治体境界を2026年版、2025年版との差を統計区境界の精度改善と説明する。一方、公式配布ページには自治体境界が2025年版との記載がある。本データは採用した2026年版ZIPおよび同梱説明書の基準を使用し、別年の境界を合成しない。
* 原典の表示縮尺・精度の目安は1:10,000であり、サンプリング単位とは異なる。格子化によって原典境界以上の精度が得られるわけではない。小さな統計区や細い区域は粗い格子で画素化されない場合がある。
* 区域図は陸域専用のマスクではない。背景値だけから水域や外国を判定しない。原典コードは照合の識別子、原典ID値・GisWordBookコードは本版内の値であり、異なる版にわたる恒久IDとして使用しない。
* 原典名称の文字を保持するため、CP932版の辞書は収録しない。本区域図は法的な境界位置や土地の権利を確定するものではない。
