# Stats NZ Statistical Area 2 2026

## 1. 概要

Stats NZのStatistical Area 2（SA2）2026年版を、Territorial Authority（TA）とSA2の2段階で参照できる区域図・名称辞書として収録する。区域図の非ゼロ画素値は同梱GisWordBookのコードであり、原典SA2コードとの対応は`names.csv`で確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | Stats NZ Statistical Area 2 2026 |
| リリースパッケージID | `nz-2026-stats-govt-nz-sa2-stat-sa2` |
| 対象地域 | Stats NZのSA2 2026年版が対象とするニュージーランドの地域。 |
| 対象区域 | SA2、計2,396区域。うち2,380区域は形状を持ち、16区域は形状を持たない。 |
| 入力座標系 | NZGD2000 / New Zealand Transverse Mercator 2000（EPSG:2193）。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | 原典のEPSG:2193座標をPROJによりEPSG:4326へ再投影する。 |
| 原典版・基準時点 | Statistical Area 2 2026、2026-01-01時点。TAの所属にはStats NZのMeshblock Higher Geographies 2026の対応を用いる。 |

### 1.1 対象範囲

原典のSA2全2,396区域を採用する。水域を表すSA2、TA所属外の区域も採用し、区域名や陸地面積を理由に除外しない。形状を持つ2,380区域を区域図の対象とする。形状なし16区域は辞書と`names.csv`には含めるが、区域図に画素を持たない。

SA2からTAへの所属は2026年版の公式対応に従う。67のTAに属する2,354区域にはそのTA名を付け、公式コード`999`（Area Outside Territorial Authority）の42区域はTA所属外である。所属外42区域のうち26区域は形状を持ち、16区域は形状を持たない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | NONE | 外洋・湾口等に独立したSA2がある一方、陸地を含むSA2にも水域が含まれ得る。原典の区域形状を保持し、追加の海岸線マスクで水域を一律に除外しない。 |
| 内水面 | NONE | 湖沼・河川等を一律に除外しない。独立した内水面SA2はその区域として保持し、それ以外は原典の区域形状に従う。 |

### 1.3 領域・境界

ニュージーランドの原典SA2収録範囲を対象とし、島嶼とTA所属外の区域も含む。原典の離れたポリゴンは同じSA2として保持し、経度180度付近の東西両側の形状も採用する。原典にない非図化区域の形状や基準時点以降の境界変更は補わない。

| 項目 | 扱い | データとしての意味・備考 |
| --- | --- | --- |
| 国境側の境界 | 該当なし | 収録対象に隣接する国・地域との陸上の国境区間はない。海岸側の扱いは第1.2節に従う。 |
| 対象領域外 | 背景値 | 採用区域面の外側。 |
| 対象領域内の未割当地点 | 背景値 | 採用面に穴・区域間の隙間がある場合の未割当地点、またはサンプリングで区域が選ばれなかった地点。 |

TA所属外には水域だけでなく陸地を持つ島嶼も含まれ、TA所属外という値だけで水域を判定できない。第1.2節の水域の状態から、区域コードは陸域専用の値ではなく、すべての水際線を識別できない。背景値だけから水域・領域外・内部の未割当地点を区別しない。

形状は東経・西経の両側に分布するため、画面表示時に日付変更線での座標の取り扱いに注意する。

格子化により境界のずれや背景画素が生じ得る。区域図の境目を正確な国境線・原典のベクトル境界として使用しない。

### 1.4 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | SA2の6桁コード`SA22026_V1_00`。原典SHPでは対応する`SA22026_V1`を文字列として保持する。TA所属は2026年版の公式対応表で同コードに結合する。 |
| 原典ID値 | remap前のGisRaster値は6桁のSA2コードを整数として解釈した値。正の整数で、本版の2,396区域に対して一意。 |
| 背景値 | `0`。区域コードが割り当てられていない地点を表し、辞書レコードを指さない。対象領域と背景になる条件は第1.3節を参照。 |
| GisWordBookコード | 第3.2節の名称パスに、SA2コードの昇順で1から採番する。コード範囲は1～2,396。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書のレコードおよび`names.csv`の`wordbook_code`に対応する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 第1.1節で形状を持つSA2を、第1.3節の対象領域でGisWordBookコードにより表す。 |
| GisWordBook | `[TA名または空文字列, SA2名]`の固定2スロット。両文字コード版は同一のコードと名称パスを持つ。 |
| names.csv | `wordbook_code,GRVALUE,SA2_CODE,SA2_NAME,SA2_NAME_ASCII,TA_CODE,TA_NAME,LAND_AREA_SQ_KM,AREA_SQ_KM,HAS_GEOMETRY`の10列。SA2ごとに1行、計2,396行。 |
| codemap | 製造時に原典ID値をGisWordBookコードへ変換する対応表。リリースZIPには含めない。 |

`names.csv`の`SA2_CODE`は原典の6桁コードを文字列として保持し、`GRVALUE`は同じコードを整数化した直接値である。`TA_CODE`と`TA_NAME`には公式対応の値を保持するため、TA所属外も`999`と`Area Outside Territorial Authority`で識別できる。`LAND_AREA_SQ_KM`と`AREA_SQ_KM`は原典SHPの属性値で、形状なし区域では原典どおり空欄とする。`HAS_GEOMETRY`は`true`または`false`で形状の有無を表す。`SA2_NAME`はマクロンを含む原典名称、`SA2_NAME_ASCII`は原典のASCII名称である。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | 公式TA名。公式コード`999`のTA所属外区域は空文字列。 | 可。所属外のみ空文字列。 |
| 区域2 | マクロンを含む原典SA2名。 | 不可。 |

所属外の区域も区域1を詰めず、2スロットを保持する。共通の国名やRegional Councilは階層に含めない。名称パスは2スロット全体で識別し、区域2だけが同名でも集約しない。本版では2,396区域の名称パスに重複はない。個別区域の原典コード、ASCII名称およびTAコードは`names.csv`で確認する。

## 5. 備考・既知の制約

- 形状のある区域でも、小島や狭い区域は粗い格子で画素化されない場合がある。
- 異なる版のGisWordBookコードを恒久的な区域IDとして利用しない。
- 原典名称のマクロンを保持するため、CP932版の辞書は収録しない。
- 区域図は統計・地図表示用であり、土地の権利、法的境界、測量、航海または緊急対応の判断には用いない。
