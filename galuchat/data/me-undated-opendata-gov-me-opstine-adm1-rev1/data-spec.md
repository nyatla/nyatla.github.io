# モンテネグロ原典収録自治体区分（基準年不詳）

## 1. 概要

モンテネグロ環境保護庁が公開するOpštineを基に、原典収録の自治体区分と名称なし区域を参照できる区域図・名称辞書を収録する。境界基準年は不詳であり、現行自治体を網羅する区域図とは説明しない。各非ゼロ画素は同梱GisWordBookコードを指し、原典objectidとの対応はnames.csvで確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | モンテネグロ原典収録自治体区分（基準年不詳） |
| リリースパッケージID | `me-undated-opendata-gov-me-opstine-adm1` |
| 対象地域 | 原典Opštine.shpに収録されたモンテネグロの範囲。 |
| 対象区域 | 原典26図形。21種類の自治体名称と、原典objectid=22の名称なし区域を収録する。 |
| 入力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | なし。原典の経緯度を保持する。 |
| 原典版・基準時点 | 境界基準年は不詳。`undated`は年度不詳を示す。公開リソース更新日は2024-12-12、DBF書出し日は2024-11-12であり、境界基準年を表さない。 |

### 1.1 対象範囲

原典26図形を採用する。区域階層は原典nameによる一階層とし、上位区域の所属を追加しない。

原典objectid=22も独立区域として保持する。自治体への推測割当て、名称補完、水域としての除外は行わない。採用区分は原典に従う。

名称なし区域の正式な種別・所属・境界定義は未確認であり、他資料との重なりから全域を水面と確定しない。図形表現上の補正が必要な場合も、区域の推測変更・黙示的な除外を行わない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `CUSTOM` | 原典の採用区域面の外側の海域だけを除外し、面内の湾内等の水域はその区域として保持する。追加の海岸線マスクによる一律除外は行わない。 |
| 内水面 | `NONE` | 湖沼・河川を一律に除外せず、原典面に含まれる水域を保持する。名称なし区域の採用は第1.1節に従い、水面・非水面を識別する属性は付与しない。 |

### 1.3 領域・境界

モンテネグロの原典Opštine全26図形の収録範囲を対象とし、Tivatの本体と小さな4面を含む全Polygon部分を保持する。名称による辞書コードの集約を理由に形状を削除せず、新設自治体の境界を別資料から補完しない。

| 項目 | 扱い | データとしての意味・備考 |
| --- | --- | --- |
| 国境側の境界 | 原典準拠 | 採用する原典区域の境界に従い、別の国境資料による補正は行わない。 |
| 対象領域外 | 背景値 | 採用区域面の外側。 |
| 対象領域内の未割当地点 | 背景値 | 採用面に穴・区域間の隙間がある場合の未割当地点、またはサンプリングで区域が選ばれなかった地点。 |

名称なしの原典objectid=22にも独立した区域コードがあり、空名称は背景を意味しない。背景値だけから水域・領域外・内部の未割当地点を区別できず、区域コードも陸域専用の値ではない。

格子化により境界のずれや背景画素が生じ得る。区域図の境目を正確な国境線・原典のベクトル境界として使用しない。

### 1.4 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | Opštine.shpのobjectid。ファイル内の図形識別子であり、国の公式自治体コードではない。 |
| 原典ID値 | `GRVALUE = objectid`。採用値は1〜17、19〜27の26個の正の整数。欠番18を新たな区域として補わない。 |
| 背景値 | `0`。区域コードが割り当てられていない地点を表し、辞書レコードを指さない。対象領域と背景になる条件は第1.3節を参照。 |
| GisWordBookコード | 第3.2節の表示グループに、各グループの最小objectidの昇順で1〜22を採番する。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は辞書の葉レコードおよびnames.csvのwordbook_codeに対応する。 |

Tivatの原典objectid=23〜27は同じ辞書コードへ対応する。

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 第1.3節の対象領域で、原典収録区分をGisWordBookコードで表す。 |
| GisWordBook | 原典nameを表示する固定1区域スロット。21種類の非空名称と1件の空名称、合計22葉レコード。UTF-8版とUTF-16LE版は同じコード空間・レコード順序・文字列を持つ。 |
| names.csv | `wordbook_code,GRVALUE,objectid,name`の4列。原典図形ごとに1行、26行。 |

objectid、GRVALUE、wordbook_codeは整数の10進表現、nameは原典のUTF-8名称である。nameの空値は空文字列として保持し、補完名やnullという表示文字列へ置き換えない。複数図形が同じwordbook_codeを持つ場合も、各行の原典objectidを保持する。

codemapは原典ID値と辞書コードの対応として製造時のみ使用する。リリースでの照合はnames.csvを使用する。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | 原典nameによる自治体名または名称なし区域の空文字列。 | 不可 |

固定1区域スロットとし、名称なし区域にも空文字列のスロットを保持する。属性スロット・共通の国名・上位区域・原典objectidはStringSetへ含めない。

同じ非空名称は一つの表示グループへ集約し、空名称は原典objectidごとに独立したグループとする。これは区域の物理的な結合を意味しない。値の解釈は第1.3節に従う。

空名称を表示できない利用側では、names.csvの原典objectidとの対応を参照する。

## 5. 備考・既知の制約

- 小島・細い区域・飛地は、粗い格子で画素として選ばれない場合がある。
- サンプリング単位は原典の位置精度や法的境界の精度を高めるものではない。
- GisWordBookコードと原典ID値は本版の値空間であり、異版にわたる恒久IDではない。
- 本区域図は法的な境界・土地の権利を確定する資料ではない。
