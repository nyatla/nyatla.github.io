# 令和2年国勢調査 町丁・字等境界データセット

## 1. 概要

本データセットは、総務省統計局および政府統計の総合窓口（e-Stat）が提供する「令和2年国勢調査 町丁・字等境界データ」を、Galuchatのオフライン逆ジオコーディング用に加工したリリースパッケージである。日本全国の小地域統計区域を、WGSMapSet/3の区域地図とGisWordBook/0の名称辞書として提供する。

| 項目 | 内容 |
| --- | --- |
| データセット名 | 令和2年国勢調査 町丁・字等境界データ |
| リリースパッケージID | `jp-2020-e-stat-go-jp-a002005212020-stat-small-area` |
| 対象地域 | 日本全国 |
| 対象区域 | 令和2年国勢調査の町丁・字等境界による小地域統計区域 |
| 入力座標系 | JGD2011地理座標（EPSG:6668） |
| 出力座標系 | WGS 84互換の緯度経度格子 |
| 座標変換 | なし。入力のJGD2011座標値を再投影・測地系変換せず、WGS 84互換の座標値として格納する。 |
| 原典版・基準時点 | `A002005212020`、令和2年国勢調査（2020年） |

### 1.1 対象範囲

47都道府県の原典Shapeファイルに収録された町丁・字等境界を統合した小地域統計区域を採用する。

本データは統計調査のために設定された区域である。行政区域、住居表示、土地利用または一般的な地名の境界と一致するとは限らず、それらの正確性を保証するものではない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `NONE` | 外水面は一律に除外されず、統計区域が残る場所と区域が割り当てられない場所が混在する。原典のポリゴンを採用し、追加の水域クリップは行わない。 |
| 内水面 | `NONE` | 湖沼などの内水面にも統計区域が割り当てられる場所がある。原典のポリゴンを採用し、追加の水域クリップは行わない。 |

### 1.3 領域・境界

日本全国の原典町丁・字等境界の収録範囲を対象とし、島嶼、港湾区域、公有水面その他の統計区域も原典どおり採用する。

| 項目 | 扱い | データとしての意味・備考 |
| --- | --- | --- |
| 国境側の境界 | 該当なし | 収録対象に隣接する国・地域との陸上の国境区間はない。海岸側の扱いは第1.2節に従う。 |
| 対象領域外 | 背景値 | 採用区域面の外側。 |
| 対象領域内の未割当地点 | 背景値 | 採用面に穴・区域間の隙間がある場合の未割当地点、またはサンプリングで区域が選ばれなかった地点。 |

背景値だけでは領域外、水域、内部の未割当地点を区別できない。区域コードも陸域のみを示す値ではなく、水域の扱いは第1.2節に従う。

都道府県境は原典どおりであり、隣接都道府県間で厳密に接合していない場合がある。原典由来の不接合を別資料で補正しない。

格子化により境界のずれや背景画素が生じ得る。区域図の境目を正確な国境線・原典のベクトル境界として使用しない。

### 1.4 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | `PREF`、`CITY`、`S_AREA`が表す小地域統計区域の識別子。 |
| 原典ID値 | rawGisRasterの値。`((PREF * 1000 + CITY) * 1_000_000) + S_AREA`で計算する。 |
| 背景値 | `0`。区域コードが割り当てられていない地点を表し、辞書レコードを指さない。対象領域と背景になる条件は第1.3節を参照。 |
| GisWordBookコード | `x_district_id + 1`による1始まりの整数値。対応するGisWordBookの葉レコードを示す。 |
| マップコード | 原典ID値をcodemapで変換したGisWordBookコード。リリース利用時は同じ接頭辞のGisWordBookで解釈する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 第1.3節の対象領域に属する町丁・字等の小地域統計区域を、GisWordBookコードで表す。 |
| GisWordBook | 都道府県、市区町村、小地区、下位地区から成る固定4階層の名称辞書。 3種類の文字コード版はレコード順序、コードおよび論理内容が同一である。 |
| codemap | 原典ID値とGisWordBookコードの対応。製造時だけ使用し、リリースパッケージには含めない。 |

### 3.2 StringSet

GisWordBookの各レコードは次の4スロットの固定長パスを持つ。空スロットは詰めず、国名などの共通ノードは含めない。

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | 都道府県。原典の都道府県名称。 | 不可 |
| 区域2 | 市区町村。原典の市区町村名称。 | 不可 |
| 区域3 | 小地区。原典の町丁・字等名称。 | 不可 |
| 区域4 | 下位地区。原典の下位地区名称。 | 可。存在しない場合は空文字列。 |

同じ表示名の区域が複数存在する場合も、GisWordBookコードで区別する。
