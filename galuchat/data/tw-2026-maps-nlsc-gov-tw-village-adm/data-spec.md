# 內政部國土測繪中心 村里界圖（2026-08-17版）

## 1. 概要

本データセットは、台湾の內政部國土測繪中心（NLSC）が公開する「村里界圖(TWD97經緯度)」の2026年8月17日版を、Galuchatのオフライン逆ジオコーディング用に加工したリリースパッケージである。各地点に対応する村・里の区域地図をWGSMapSet/3で、縣市から村・里までの名称階層をGisWordBook/0で提供する。

| 項目 | 内容 |
| --- | --- |
| データセット名 | 內政部國土測繪中心 村里界圖（2026-08-17版） |
| リリースパッケージID | `tw-2026-maps-nlsc-gov-tw-village-adm` |
| 対象地域 | 台湾の原典に収録された範囲。台湾本島、金門、連江、澎湖およびその他の島嶼を含む。 |
| 対象区域 | 縣市、鄉鎮市區、村・里および未編定村里 |
| 入力座標系 | TWD97地理座標系（EPSG:3824） |
| 出力座標系 | WGS 84地理座標系（EPSG:4326） |
| 座標変換 | 入力のTWD97座標をEPSG:3824として解釈し、PROJの登録済み変換でEPSG:4326へ変換する。 |
| 原典版・基準時点 | `VILLAGE_NLSC_1150817`、2026年8月17日改訂版 |

### 1.1 対象範囲

原典の本体レイヤに含まれる7,986区域と、別レイヤの屏東縣瑪家鄉三和村1区域を採用する。三和村が本体の6区域と重なる部分は三和村を優先し、本体側から差し引いた区域を収録する。原典に含まれる島嶼や未編定村里も除外しない。

本データは原典の行政上の帰属を表し、法的な境界、地籍界または住所の境界を確定するものではない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `SIMPLE` | 海側は原典の村里界ポリゴンの外縁に従って背景値`0`となる。原典は紙の村里界資料を数値化したものであり、測量値に基づく詳細な海岸線による補正は行っていない。 |
| 内水面 | `NONE` | 湖沼・ダム湖などにも村里区域が割り当てられる。原典の区域図形を採用し、追加の内水面クリップは行っていない。 |

### 1.3 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | 11文字の`VILLCODE`。通常の村里は数字、未編定村里は区分英字を含む。 |
| 原典ID値 | 製造時に`VILLCODE`順で1から付与する`GRVALUE`。raw GisRasterへ格納し、原典の行政コードそのものではない。現版の範囲は1～7,987。 |
| 背景値 | `0`。区域が設定されていない地点を表し、海陸判定値ではない。 |
| GisWordBookコード | `VILLCODE`順の初出パスに1から付与する。通常村里7,781件と未編定村里47件の合計7,828件。未編定の206区域は`TOWNCODE`ごとに同じ名称パスへ集約する。 |
| マップコード | 原典ID値を製造時のcodemapで変換したGisWordBookコード。非0画素は同梱GisWordBookの対応する名称パスを示す。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 各地点にGisWordBookコードを格納する。`0`は背景、非0値は対応する村里の名称パスを表す。 |
| GisWordBook | 縣市、鄉鎮市區、村里の固定3階層からなる名称辞書。2種類の文字コード版はレコード順と論理内容が同じ。 |
| names | 各原典区域の`VILLCODE`、名称・英語名などの原典属性、`GRVALUE`および対応する`wordbook_code`を保持する。未編定区域は複数行が同じ辞書コードを指す。 |
| codemap | 製造時に`GRVALUE`をGisWordBookコードへ変換する対応表。リリースパッケージには含めない。 |

### 3.2 StringSet

GisWordBookの各レコードは次の3スロットの固定長パスを持つ。国・地域名の共通ノードは含めない。原典で村里名を持たない区域は、空欄のままにせず「未編定村里」として`TOWNCODE`ごとに集約する。

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | `COUNTYNAME`が表す縣市名。 | 不可 |
| 区域2 | `TOWNNAME`が表す鄉鎮市區名。 | 不可 |
| 区域3 | `VILLNAME`が表す村里名、または「未編定村里」。 | 不可 |

同名の村里は縣市名・鄉鎮市區名との組合せで識別する。辞書コードと原典の`VILLCODE`・`GRVALUE`との対応は同梱`names.csv`で確認できる。

## 5. 備考・既知の制約

* 三和村の補助レイヤを優先する重複解決は本リリース固有の採用規則であり、原典提供者が指定した統合規則ではない。
* 未編定村里の206区域は47の辞書レコードへ集約されるため、地図画素値だけから個々の`VILLCODE`は復元できない。`names.csv`には原典区域ごとの対応を保持する。
* 格子サンプリング後の区域境界は、原典ベクトルの境界と完全には一致しない。小さな区域は解像度によって表現されない場合がある。
* 原典の名称・区域・行政上の帰属は2026年8月17日版に基づく。原典の更新後は現況と異なる場合がある。
