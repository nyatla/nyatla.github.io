# ルーマニアANCPI地方行政区域（2025-03-26）

## 1. 概要

ルーマニア国家地籍・不動産公示庁（ANCPI）のUnități administrativ-teritorialeを基に、県・ブカレストと地方行政区域を参照できる区域図・名称辞書を収録する。末端区域は原典のUATとし、ブカレストは6セクターの粒度を保持する。区域図の非ゼロ値は同梱GisWordBookのコードであり、原典コードとの対応はnames.csvで確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | ルーマニアANCPI地方行政区域（2025-03-26） |
| リリースパッケージID | `ro-2025-ancpi-ro-uat-adm` |
| 対象地域 | 原典のUAT面が表すルーマニア全域。本土、島状部分および飛地を含む。 |
| 対象区域 | UAT・ブカレストのセクター、計3,186区域。上位名称は41県とブカレストの42区域。 |
| 入力座標系 | Romania_double_stereo（Pulkovo 1942、Oblique Stereographicの非標準定義）。提供元の説明に従いEPSG:3844相当として解釈する。 |

### 1.1 対象範囲

原典の3rdOrder全3,186区域を末端区域として採用する。内訳はComuna（村落自治体）2,862区域、Oras（市・町）216区域、県都以外のMunicipiu 62区域、県都のMunicipiu 40区域、ブカレストのセクター6区域である。UATの種類は区域階層ではなく末端区域の属性として保持する。

名称階層は県・ブカレスト→UAT・セクターの2段階とする。上位名称は同じ版のANCPI県データUnitate_administrativa_judetのnameを使用し、所属は原典の県コードに従う。県の面を別の画素値として重ねたり、県境に合わせてUAT面を切り直したりしない。

ブカレストは県と同じ上位スロットにBUCUREŞTIを収録し、その下にBUCUREŞTI SECTORUL 1～6を別の末端区域として保持する。ブカレスト全体の面を追加せず、6セクターを1区域へ統合しない。コムーナに属する個々の村、統計区、国の共通ノードは収録しない。

名称は両原典のルーマニア語表記を保持する。大文字・小文字やŞ・Ţ等の字形を一律に置換せず、翻訳・推測による名称補完を行わない。島状部分、飛地、複数の図形部分、穴および隣国との境界は原典に従い、別の国境資料で補正しない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `CUSTOM` | 原典のUAT面の外側の外水面は背景とし、面に含まれる水面はその区域として保持する。除外条件は原典の採用区域面の外側であること。海岸側の外縁に従い、別の海岸線・海域マスクは適用しない。 |
| 内水面 | `NONE` | 湖沼・河川・貯水池を一律に除外せず、原典のUAT面に含まれる水面はその区域として保持する。水面と陸域を明示的に区別する値は持たず、原典図形の穴は背景となる。追加の内水面マスクは適用しない。 |

### 1.3 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | UATのnatCode。採用3,186区域で一意の区域コード。INSPIREのnamespaceとlocalIdの組、IdおよびIFCIDとは区別する。 |

| 背景値 | `0`。末端区域の外側、原典図形の穴、サンプリングで区域が選ばれなかった画素。水域専用の値ではない。 |

| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書の葉レコードとnames.csvのwordbook_codeに対応する。全解像度で同じ辞書コード空間を使用する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 各地点のUATまたはセクターをGisWordBookコードで表す。背景は0。 |
| GisWordBook | `[県・ブカレスト名, UAT・セクター名, UAT種類]`の固定3スロット。先頭2スロットが区域階層、末尾が末端区域の属性。UTF-8版とUTF-16LE版は同じコード空間・レコード順序を持つ。 |
| names.csv | `wordbook_code,GRVALUE,COUNTY_CODE,COUNTY_NAME,UAT_CODE,UAT_NAME,UAT_TYPE,LOCAL_ID`の8列。ヘッダーを除くデータ行は末端区域ごとに1行、計3,186行。 |

GRVALUEは原典ID値、wordbook_codeは最終マップ値である。COUNTY_CODE・COUNTY_NAMEは県原典のnatCode・name、UAT_CODE・UAT_NAME・UAT_TYPE・LOCAL_IDはUAT原典のnatCode・name・natLevName・localIdに対応する。コード列は原典の10進コード文字列を保持し、固定桁数へのゼロ埋めや別の行政コード体系への変換は行わない。

COUNTY_CODEはUATのlocalIdの`1.<県コード>.<UATコード>`における県コードと一致する。県原典の同じnatCodeに対応する名称をCOUNTY_NAMEおよび区域1として持つ。この所属関係はコードによるものであり、UAT名の類似性や代表点の位置から推測したものではない。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | Județ（県）または同格のブカレストの名称。県原典のname。 | 不可 |
| 区域2 | UATまたはブカレストのセクターの名称。UAT原典のname。 | 不可 |
| 属性1 | 末端区域の種類。UAT原典のnatLevName。 | 不可 |

属性1は原典のComuna、Oras、Municipiu, altul decat resedinta de judet、Municipiu resedinta de judet、Sectoarele municipiului Bucurestiのいずれかを保持する。種類を名称階層に挿入しない。国名等の共通ノード、原典コードの属性および空スロットは含めない。

区域1・区域2の名称パスで末端区域を識別する。本版では全3,186区域の名称パスが一意であり、別natCodeの区域が同じ辞書レコードに集約されることはない。同じUAT名でも所属県が異なれば別レコードとなる。同じnatCodeの島状部分・飛地・複数の図形部分には同じ辞書コードを割り当てる。

## 5. 備考・既知の制約

* UATは地方行政区域の面であり、個々の村や建物の密集範囲を意味しない。県名は県原典から補完するが、末端の区域形状はUAT原典に従う。
* 区域コードだけから水面と陸域を区別できず、背景値0だけから水域や外国を判定することもできない。原典の海岸側の外縁は採用するが、別の詳細な水際線との一致を保証しない。
* 区域図は原典の区域を格子化したものであり、境界付近では元のベクトル境界と判定が一致しない場合がある。小島・細い区域・飛地は粗い格子で画素化されない場合がある。辞書の区域件数は、各解像度に現れる非ゼロ値の種類数を保証するものではない。
* 県コードとUATコードは異なる階層の値である。原典との照合にはnames.csvの各コード列を用いる。GisWordBookコードは本版の辞書レコードを参照する値であり、異なる版の恒久的な区域IDとして使用しない。
* 名称・所属・区域形状は採用した2025-03-26版に依存し、その後の行政変更は反映しない。名称の字形を保持するためCP932版の辞書は収録しない。本区域図は法的な境界位置や土地の権利を確定するものではない。
