# カタール自治体区域（2015年国勢調査付属境界）

## 1. 概要

National Planning Councilが公開する2015年国勢調査の事業所・従業者統計に付属する自治体境界を基に、カタールの8自治体を参照できる区域図・名称辞書を収録する。区域図の非ゼロ値は同梱GisWordBookのコードである。自治体の英語名称を使用し、事業所数・従業者数等の統計値は収録しない。

| 項目 | 内容 |
| --- | --- |
| データセット名 | カタール自治体区域（2015年国勢調査付属境界） |
| リリースパッケージID | `qa-2015-data-gov-qa-npc-od-c0-00621-adm1` |
| 対象地域 | 採用した原典自治体面が表すカタールの範囲。原典に収録された島嶼・飛地を含む。 |
| 対象区域 | Municipality（自治体）8区域。国直下の1段階の区域階層。 |
| 入力座標系 | WGS 84経緯度（EPSG:4326、GeoJSON）。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | 入力・出力ともWGS 84経緯度であり、再投影・測地系変換は行わない。 |
| 原典版・基準時点 | 2015年国勢調査に付属する自治体境界。統計年は2015年、公式ポータルのデータ更新日は2025-06-02。境界図形自体の基準日は未確認であり、2015年・2025年・取得年のいずれとも断定しない。 |

### 1.1 対象範囲

原典の8自治体をすべて採用する。対象はAl-Daayen、Al-Khor and Al-Thakhira、Al-Rayyan、Al-Shamal、Al-Sheehaniya、Al-Wakra、Doha、Umm Salalであり、名称は原典のmunicipalityの表記を保持する。下位のZone・District等の区域は収録しない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `CUSTOM` | 原典自治体面の外側の海域だけを除外し、面内の沿岸水域は自治体の区域として保持する。追加の海岸線マスクは使用せず、外水面の全面除外や詳細な水際線との一致は保証しない。 |
| 内水面 | `NONE` | 湖沼・河川等を一律に除外せず、原典自治体面に含まれる水面はその自治体の区域として保持する。原典は水面を区別する属性を持たず、内水面専用の値は作らない。追加の内水面マスクは使用しない。 |

### 1.3 領域・境界

カタールの原典8自治体の収録範囲を対象とする。離れたポリゴン部分・島嶼を保持し、原典にある小さな重複・隙間を独自に解消しない。

| 項目 | 扱い | データとしての意味・備考 |
| --- | --- | --- |
| 国境側の境界 | 原典準拠 | 採用する原典区域の境界に従い、別の国境資料による補正は行わない。 |
| 対象領域外 | 背景値 | 採用区域面の外側。 |
| 対象領域内の未割当地点 | 背景値 | 個々の原典区域に穴がなくても、区域間の隙間やサンプリングで区域が選ばれなかった地点は背景となり得る。 |

背景値だけでは領域外、水域、内部の未割当地点を区別できない。区域コードも陸域のみを示す値ではなく、水域の扱いは第1.2節に従う。

重複する地点に複数の自治体コードを返すものではなく、第4章のサンプリング方式によりセルごとに単一コードを持つ。

格子化により境界のずれや背景画素が生じ得る。区域図の境目を正確な国境線・原典のベクトル境界として使用しない。

### 1.4 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | 採用GeoJSONには行政コード・専用の区域IDはない。8区域すべてで一意の英語自治体名municipalityを、本版の原典レコードの照合キーとして使用する。 |
| 原典ID値 | remap前のGisRaster値は、municipalityを大文字・小文字および空白を保持したASCII辞書順に並べた1始まりの順位（1～8）。Galuchatが付ける対応値であり、公式行政コードではない。 |
| 背景値 | `0`。区域コードが割り当てられていない地点を表し、辞書レコードを指さない。対象領域と背景になる条件は第1.3節を参照。 |
| GisWordBookコード | 原典ID値と同じ名称順に1から8まで採番する。 |
| マップコード | 原典ID値と同値のGisWordBookコード。非ゼロ値は同梱辞書の葉レコードとnames.csvのwordbook_codeに対応する。全解像度で同じ辞書コード空間を使用する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 第1.3節の対象領域で、自治体をGisWordBookコードで表す。 |
| GisWordBook | [自治体名]の固定1スロット。UTF-8版とUTF-16LE版は同一のコード空間・レコード順序を持つ。 |
| names.csv | `wordbook_code,GRVALUE,MUNICIPALITY`の3列。ヘッダーを除くデータ行は自治体ごとに1行、計8行。 |

GRVALUEは第1.4節の原典ID値、MUNICIPALITYは採用GeoJSONのmunicipalityに対応する。wordbook_codeとGRVALUEは同じ値であり、行政コードを表す列は設けない。原典のgeo_pointは代表点であって区域境界ではなく、区域判定や辞書に使用しない。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | Municipality（自治体）の英語名称municipality。 | 不可 |

国名等の共通ノード、下位区域、空スロットおよび属性スロットは含めない。区域1の名称で辞書レコードを識別する。本版では8名称すべてが一意で、異なる自治体の名称集約は生じない。同じ自治体の島嶼・飛地・複数の図形部分には同じ辞書コードを割り当てる。採用GeoJSONに含まれないアラビア語名称を別資料から補完しない。

原典名称は収録された表記のまま保持し、別綴りへの正規化や翻訳を行わない。

## 5. 備考・既知の制約

- 現在の行政界との一致を保証しない。
- 小島・細い区域・飛地は、粗い格子で画素として選ばれない場合がある。
- GisWordBookコードと原典ID値は本版の対応値であり、異なる版をまたぐ恒久的な行政区域識別子として使用しない。
- 自治体の法的な境界位置、土地の権利および国境を確定する用途には使用しない。
