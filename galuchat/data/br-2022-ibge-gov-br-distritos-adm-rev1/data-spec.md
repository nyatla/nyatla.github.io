# ブラジルIBGE地区区域（Censo Demográfico 2022）

## 1. 概要

ブラジル地理統計院（IBGE）のCenso Demográfico 2022に付属するMalha de Distritosを基に、州・連邦区、自治体相当区域、地区を参照できる区域図・名称辞書を収録する。通常の地区に加え、原典の州所属の湖面運用区域も保持する。区域図の非ゼロ値は同梱GisWordBookのコードであり、原典コードおよび区域種別との対応はnames.csvで確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | ブラジルIBGE地区区域（Censo Demográfico 2022） |
| リリースパッケージID | `br-2022-ibge-gov-br-distritos-adm` |
| 対象地域 | 原典の地区・運用区域が表すブラジル全域。本土、島嶼および飛地を含む。 |
| 対象区域 | 通常地区10,698区域と州所属の湖面運用区域1区域、計10,699区域。通常地区の上位名称は27の州・連邦区と5,570の自治体相当区域。 |
| 入力座標系 | SIRGAS 2000経緯度（EPSG:4674）。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | 入力をEPSG:4674として解釈し、EPSG:4326へ測地系変換する。両座標系を同一とみなした座標系ラベルの付替えは行わない。 |
| 原典版・基準時点 | Censo Demográfico 2022の確定版Malha de Distritos。区域の基準日は2022年7月31日。原典ファイルは`BR_distritos_CD2022.zip`。 |

### 1.1 対象範囲

原典の全10,699区域を採用する。通常の末端区域はDistrito（地区）とし、その所属をUnidade da Federação（州・連邦区）、Município相当（自治体相当区域）の順に表す。所属は原典のコードに従い、各階層の名称は原典のポルトガル語表記を保持する。州や自治体の面を別の画素値として重ねない。

BrasíliaとFernando de Noronhaは、原典の統計登録上の自治体相当区域として区域2に収録する。このスロットは、行政制度上の通常のMunicípioだけに限定したものではない。

地区・自治体のコードと名称を持たない湖面の運用区域は、Rio Grande do Sul州に直属する別種の末端区域として保持する。原典ではLagoa dos PatosとLagoa Mirimを合わせた1レコードであり、2湖に別々のコードは割り当てない。実在しない自治体や地区を補わず、辞書の表示名だけを`Área operacional: Lagoa dos Patos e Lagoa Mirim`とする。この表示名は本リリースの補完表記であり、原典の地区名称ではない。

国の共通ノード、Grande Região（大地域）、Região Geográfica Intermediária（中間地理地域）、Região Geográfica Imediata（即時地理地域）、Concentração Urbana（都市集中地域）は名称階層に含めない。別レイヤのSubdistrito、Bairro、水域専用分類を持つSetor Censitárioも収録しない。

Distritoは行政上の地区であり、国勢調査の最小集計区域であるSetor Censitárioとは異なる。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `CUSTOM` | 原典の地区面・州所属の運用区域面の外側の外水面だけを除外し、面内の沿岸水域はその区域として保持する。水際形状は原典に従い、別の海岸線・海域マスクは適用しない。 |
| 内水面 | `NONE` | 湖沼・河川を一律に除外せず、通常地区の面に含まれる内水面はその地区として保持する。Lagoa dos Patos・Lagoa Mirimの運用区域は別コードで識別できるが、通常地区内の内水面全体を陸域と区別する値は持たない。この混合状態のため全体をEXPLICITとはしない。追加の内水面マスクは適用しない。 |

### 1.3 領域・境界

ブラジルの原典BR_distritos_CD2022全10,699区域の収録範囲を対象とし、Lagoa dos Patos・Lagoa Mirimを合わせた湖面運用区域と、原典に含まれる島嶼・飛地・全図形部分・穴も保持する。

| 項目 | 扱い | データとしての意味・備考 |
| --- | --- | --- |
| 国境側の境界 | 原典準拠 | 採用する原典区域の境界に従い、別の国境資料による補正は行わない。 |
| 対象領域外 | 背景値 | 採用区域面の外側。 |
| 対象領域内の未割当地点 | 背景値 | 採用面に穴・区域間の隙間がある場合の未割当地点、またはサンプリングで区域が選ばれなかった地点。 |

湖面運用区域はAREA_TYPEと区域コードで識別できるが、全国の水域を網羅する分類ではない。区域コードを陸域判定に用いず、背景値だけから水域・外国・内部の未割当地点を区別しない。

格子化により境界のずれや背景画素が生じ得る。区域図の境目を正確な国境線・原典のベクトル境界として使用しない。

### 1.4 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | 通常地区は`CD_DIST`の9桁コード文字列。先頭7桁は`CD_MUN`、先頭2桁は`CD_UF`に対応する。州所属の湖面運用区域には地区・自治体の原典IDがなく、原典の欠損をnames.csvでも空文字列として保持する。 |
| 原典ID値 | remap前のGisRaster値`GRVALUE`。通常地区は`CD_DIST`を10進整数にした値で、本版では110,001,505から530,010,805までの欠番を含む値空間。地区コードを持たない湖面運用区域には加工用ID値`1`を割り当てる。この値はIBGEの地区コードではなく、通常地区の整数値とは衝突しない。 |
| 背景値 | `0`。区域コードが割り当てられていない地点を表し、辞書レコードを指さない。対象領域と背景になる条件は第1.3節を参照。 |
| GisWordBookコード | 原典ID値の昇順に1から10,699まで採番する。湖面運用区域がコード1、通常地区は`CD_DIST`の昇順にコード2から10,699となる。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書の葉レコードとnames.csvの`wordbook_code`に対応する。全解像度で同じ辞書コード空間を使用する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 第1.3節の対象領域で、地区または州所属の湖面運用区域をGisWordBookコードで表す。 |
| GisWordBook | `[州・連邦区名, 自治体相当区域名, 末端区域の表示名]`の固定3スロット。すべて区域階層であり、属性スロットは設けない。UTF-8版とUTF-16LE版は同一のコード空間・レコード順序を持つ。 |
| names.csv | `wordbook_code,GRVALUE,AREA_TYPE,CD_UF,NM_UF,CD_MUN,NM_MUN,CD_DIST,NM_DIST,DISPLAY_NAME`の10列。ヘッダーを除くデータ行は採用区域ごとに1行、計10,699行。 |

`GRVALUE`は原典ID値、`wordbook_code`は最終マップ値である。`CD_UF`、`CD_MUN`、`CD_DIST`はそれぞれ原典の2桁・7桁・9桁のコード文字列であり、先頭ゼロを保持する。`NM_UF`、`NM_MUN`、`NM_DIST`は原典名称を保持する。原典に値がないコード・名称は空文字列とし、加工用のコード・表示名で上書きしない。

`AREA_TYPE`は通常地区で`DISTRICT`、州所属の湖面運用区域で`STATE_OPERATIONAL_WATER`とする。この区域種別は本リリースの分類であり、原典の属性名ではない。`DISPLAY_NAME`は通常地区では`NM_DIST`、湖面運用区域では第1.1節の補完表記である。湖面運用区域の`CD_UF`・`NM_UF`は`43`・`Rio Grande do Sul`で、自治体・地区の原典コードと名称は空文字列となる。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | Unidade da Federação（州・連邦区）の名称。原典の`NM_UF`。 | 不可 |
| 区域2 | Município相当（自治体相当区域）の名称。原典の`NM_MUN`。 | 可。州直属の運用区域では空文字列。 |
| 区域3 | 末端区域の表示名。通常地区の`NM_DIST`または運用区域の補完表記。 | 不可 |

スロットは常に3個を保持し、空スロットがあっても詰めない。通常地区は`[NM_UF, NM_MUN, NM_DIST]`、州所属の湖面運用区域は`[NM_UF, "", DISPLAY_NAME]`（各値は第3.1節）となる。後者は州から運用区域への直属関係を表し、空の区域2が架空の自治体を意味するものではない。

国名などの共通ノード、原典コードおよび区域種別の属性はStringSetに含めない。辞書レコードは区域1・区域2・区域3の全名称パスで識別し、本版の10,699区域では異なる原典IDがこのパスを共有しない。同じ原典地区や運用区域の飛地・複数の図形部分には同じ辞書コードを割り当てる。

## 5. 備考・既知の制約

- 小島・細い区域・飛地は、粗い格子で画素として選ばれない場合がある。辞書の区域件数は、各解像度で実際に現れる区域コードの種類数を保証するものではない。
- サンプリング解像度は原典の位置精度を保証するものではなく、全区域が一定の測量精度を持つことも意味しない。
- 辞書コードは本版のレコードを参照する値であり、異なる版の恒久IDには使用しない。
- 原典の基準時点以降の行政変更は反映しない。原典名称の文字を保持するためCP932版の辞書は収録しない。本区域図は法的な境界位置や土地の権利を確定するものではない。
