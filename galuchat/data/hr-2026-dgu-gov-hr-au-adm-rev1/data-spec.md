# クロアチアDGU集落区域（2026年）

## 1. 概要

クロアチア国家測地局（DGU）のINSPIRE Administrative Unitsを基に、県相当区域、市・自治体、集落の3段階を参照できる区域図・名称辞書を収録する。末端区域はNaselje（集落区域）とし、統計区・国勢調査区は含めない。区域図の非ゼロ値は同梱GisWordBookのコードであり、原典コードとの対応はnames.csvで確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | クロアチアDGU集落区域（2026年） |
| リリースパッケージID | `hr-2026-dgu-gov-hr-au-adm` |
| 対象地域 | 原典のNaseljeが表すクロアチア全域。本土、島嶼および飛地を含む。 |
| 対象区域 | Naseljeの6,759区域。上位名称はŽupanija相当の21区域とJedinica lokalne samoupraveの556区域。 |
| 入力座標系 | ETRS89-extended / LAEA Europe（EPSG:3035）。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | EPSG:3035からEPSG:4326へ再投影・測地系変換する。 |

### 1.1 対象範囲

原典の4thOrder（Naselje）全区域を末端区域として採用する。Naseljeは建物点や市街地だけではなく、他用途の土地を含む集落の区域である。各集落について原典の所属関係に従う3rdOrder（市・自治体）と2ndOrder（県相当区域）の名称を持つ。上位区域の面を別の画素値として重ねない。

県相当区域は20県と県と同格のGrad Zagrebからなる。市・自治体にはGradとOpćinaを同じ区域階層として収録し、Zagrebも原典の各階層の所属・名称を保持する。同じ名称が異なる階層に現れても、階層を省略したり名称を書き換えたりしない。

国の共通ノード、5thOrder（Statistički krug）、6thOrder（Popisni krug）は収録しない。原典に含まれる集落の島状部分、飛地および穴は原典の区域に従う。隣国との境界を別資料で補正しない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `CUSTOM` | 原典のNaselje面に含まれない外水面は背景とし、面に含まれる水面はその集落の区域として保持する。除外条件は原典の採用区域面の外側であること。原典の海岸側の外縁に従い、別の海岸線・海域マスクは適用しない。 |
| 内水面 | `NONE` | 湖沼・河川・貯水池を一律に除外せず、原典のNaselje面に含まれる水面はその集落の区域として保持する。水面と陸域を明示的に区別する値は持たず、原典図形の穴は背景となる。追加の内水面マスクは適用しない。 |

### 1.3 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | NaseljeのnationalCode。6桁のコード文字列を保持する。原典のINSPIRE識別子はnamespace（HR.DGU.RPJ）とlocalIdの組であり、nationalCodeとは別の識別子である。 |
| 原典ID値 | remap前のGisRaster値は、NaseljeのnationalCodeを10進整数にした正の値。採用区域で一意であり、本版の範囲は19から77,003までの欠番を含む値空間。gml:idの末尾数値や上位区域のコードは使用しない。 |
| 背景値 | `0`。末端区域の外側、原典図形の穴、サンプリングで区域が選ばれなかった画素。水域専用の値ではない。 |
| GisWordBookコード | 原典ID値の昇順で、1から6,759まで採番する。0は辞書レコードを指さない。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書の葉レコードとnames.csvのwordbook_codeに対応する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 各地点の集落区域をGisWordBookコードで表す。背景は0。 |
| GisWordBook | [県相当区域名, 市・自治体名, 集落名]の固定3スロット。すべて区域階層であり、属性スロットは設けない。UTF-8版とUTF-16LE版は同一のコード空間・レコード順序を持つ。 |
| names.csv | `wordbook_code,GRVALUE,ZUPANIJA_CODE,ZUPANIJA_NAME,JLS_CODE,JLS_NAME,NASELJE_CODE,NASELJE_NAME`の8列。ヘッダーを除くデータ行は末端区域ごとに1行、計6,759行。 |

GRVALUEは原典ID値。ZUPANIJA_CODE、JLS_CODE、NASELJE_CODEは、それぞれ対応する原典のnationalCodeであり、2桁、5桁、6桁の文字列として先頭ゼロを保持する。名称は各階層の原典のクロアチア語表記を保持する。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | Županija（県相当区域）の名称。県と同格のGrad Zagrebを含む。 | 不可 |
| 区域2 | Jedinica lokalne samouprave（市・自治体）の名称。 | 不可 |
| 区域3 | Naselje（集落）の名称。 | 不可 |

国名等の共通ノードと空スロットは含めない。区域1・区域2・区域3の組で辞書レコードを識別する。本版では全名称パスが6,759区域すべてで一意であり、異なるnationalCodeの区域が同じ辞書レコードに集約されることはない。集落名だけが同じでも、所属する県・自治体が異なる区域は別レコードとなる。同じnationalCodeの飛地・複数の図形部分には同じ辞書コードを割り当てる。

## 5. 備考・既知の制約

* Naseljeは原典の集落区域であり、独立した地方自治体や建物の密集範囲を意味しない。名称階層は県相当区域、市・自治体、集落を表し、統計区・国勢調査区の階層は含まない。
* nationalCodeは階層ごとに割り当てられたコードである。上位区域と集落のコードの数字が同じでも、同じ区域を意味しない。階層別のコード列を用いて照合する。
* 区域図は原典の区域を格子化したものであり、境界付近では元のベクトル境界と判定が一致しない場合がある。小島・細い区域・飛地は粗い格子で画素化されない場合がある。
* 区域コードだけから陸域と水面を判定できず、背景値0だけから水域や外国を判定することもできない。原典の海岸側外縁は採用するが、別の詳細な水際線との一致を保証するものではない。
* GisWordBookコードは本版の辞書レコードを参照する値であり、異なる版の恒久的な区域IDとして使用しない。照合にはnames.csvに保持した原典コードを用いる。
* 原典名称の文字を保持するためCP932版の辞書は収録しない。名称・区域は採用した原典版に依存し、その後の変更は反映しない。本区域図は法的な境界位置や土地の権利を確定するものではない。
