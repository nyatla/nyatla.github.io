# アイスランド自治体区域（INSPIRE 2022年版）

## 1. 概要

INSPIRE Administrative Units (au) Icelandの2022年版から、自治体（Sveitarfélag）を参照できる区域図と名称辞書を収録する。原典の島嶼・飛び地を含む自治体区域を保持し、各非ゼロ画素を同梱GisWordBookコードへ対応付ける。原典コードと名称はnames.csvで確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | アイスランド自治体区域（INSPIRE 2022年版） |
| リリースパッケージID | `is-2022-natt-is-is-au-lmi-adm1` |
| 対象地域 | 原典自治体ポリゴンが表すアイスランド。本島と収録島嶼を含む。 |
| 対象区域 | 64自治体の一階層。 |
| 入力座標系 | 取得済みGeoPackageのWGS 84経緯度（EPSG:4326）。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | なし。取得済み経緯度を保持する。 |
| 原典版・基準時点 | `versionid=INSPIRE 2022-10-04`の2022年版。区域ごとのbeginlifespanversionは全体の版時点とは区別する。 |

### 1.1 対象範囲

`is_au_lmi_administrativeunit`の全64自治体を採用する。境界線レイヤーと行政庁所在地の点レイヤーは区域図に含めない。

上位Regionの所属は収録せず、原典の自治体コードlocalidと名称textを使用する。原典にない上位所属、最新版の名称を追加しない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `FULL` | 原典の詳細な海岸側外縁により海域を区域図から除外する。元となるIS 50Vの自治体境界は航空画像由来の海岸線更新を反映しており、追加の簡略化・海岸線マスクは適用しない。 |
| 内水面 | `NONE` | 湖沼・河川を一律に除外せず、原典自治体面に含まれる水面をその自治体として保持する。水面と非水面を区別する属性は収録しない。 |

### 1.3 領域・境界

アイスランドの原典全64自治体の収録範囲を対象とする。全Polygon部分を保持し、小島・飛地を面積によって除外せず、別資料で対象領域を追加しない。

| 項目 | 扱い | データとしての意味・備考 |
| --- | --- | --- |
| 国境側の境界 | 該当なし | 収録対象に隣接する国・地域との陸上の国境区間はない。海岸側の扱いは第1.2節に従う。 |
| 対象領域外 | 背景値 | 採用区域面の外側。 |
| 対象領域内の未割当地点 | 背景値 | 採用面に穴・区域間の隙間がある場合の未割当地点、またはサンプリングで区域が選ばれなかった地点。 |

背景値だけでは領域外、水域、内部の未割当地点を区別できない。区域コードも陸域のみを示す値ではなく、水域の扱いは第1.2節に従う。

格子化により境界のずれや背景画素が生じ得る。区域図の境目を正確な国境線・原典のベクトル境界として使用しない。

### 1.4 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | `namespace=IS.AU.LMI`内のlocalid。原典の文字列表現をnames.csvに保持する。 |
| 原典ID値 | `GRVALUE = int(localid) + 1`。0を背景用に予約し、64自治体を一意の正の整数で表す。 |
| 背景値 | `0`。区域コードが割り当てられていない地点を表し、辞書レコードを指さない。対象領域と背景になる条件は第1.3節を参照。 |
| GisWordBookコード | localidの整数昇順に1〜64を採番する。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は辞書の葉レコードおよびnames.csvのwordbook_codeに対応する。 |

localid=`0`はReykjavíkurborgを表す。原典ID値は1となり、背景として除外しない。原典ID値とマップコードの対応はnames.csvに明示する。

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 第1.3節の対象領域で、自治体をGisWordBookコードで表す。 |
| GisWordBook | 原典textを表示する固定1区域スロット。UTF-8版とUTF-16LE版は同じ64葉レコード・コード空間・文字列を持つ。 |
| names.csv | `wordbook_code,GRVALUE,localid,text,inspireid,gml_id`の6列。採用自治体ごとに1行、64行。 |

localid、inspireid、gml_idは原典の文字列、textは原典のアイスランド語名称である。発音記号付き文字やÞなどを保持し、ASCIIへの置換や名称の更新は行わない。GRVALUEとwordbook_codeは整数の10進表現である。

codemapは原典ID値と辞書コードの対応として製造時のみ使用する。リリースでの照合はnames.csvを使用する。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | 原典textによる自治体名。 | 不可 |

固定1区域スロットとし、属性スロット・共通の国名・Region・原典コードはStringSetへ含めない。64の自治体名は一意であり、異なる自治体間の名称集約は生じない。同じ自治体の島・飛び地は同じ辞書コードを持つ。

原典に暫定名称がある場合も、その収録文字列を保持する。

## 5. 備考・既知の制約

- 原典版以降の変更は反映せず、現行自治体境界との一致を保証しない。
- 小島・細い区域・飛地は、粗い格子で画素として選ばれない場合がある。
- サンプリング単位は原典縮尺1:50,000の位置精度や法的境界の精度を高めるものではない。
- GisWordBookコードと原典ID値は本版の値空間であり、異版にわたる恒久IDではない。外部照合にはnames.csvの原典識別情報を使用する。
- 本区域図は法的な境界・土地の権利を確定する資料ではない。
