# キプロス行政区域（2024年8月版）

## 1. 概要

キプロス土地・測量局の行政区域を基に、県、市・共同体、合併後の市を構成する地区、街区を参照できる区域図と名称辞書を収録する。合併した旧自治体を独立した自治体として扱わず、合併後も存続する細区画を新しい市の下位区域として保持する。区域図の非ゼロ値は同梱GisWordBookのコードであり、原典コードとの対応はnames.csvで確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | キプロス行政区域（2024年8月版） |
| リリースパッケージID | `cy-2024-data-gov-cy-administrative-units-adm` |
| 対象地域 | 採用原典の6県に属する区画が表すキプロスの範囲。北部を含む。 |
| 対象区域 | 市・共同体等の細区画615件を基礎とし、街区を持つ30区画では下位の159街区を採用する。末端区域は街区のない585区画と159街区、計744区域。 |
| 入力座標系 | CGRS93 / Cyprus Local Transverse Mercator（EPSG:6312相当）。原典PRJはCGRS_1993_LTM（ESRI:102319）表記。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | キプロスの投影座標を逆投影し、CGRS93 to WGS 84 (1)（EPSG:7721）による測地系変換を行う。 |
| 原典版・基準時点 | Administrative_Units_GR_Shapefiles_AUGUST2024、2024年8月版。2024年7月の自治体再編を原典に収録された範囲で反映する。 |

### 1.1 対象範囲

原典のΕΠΑΡΧΙΕΣ（県）、ΔΗΜΟΙ_ΚΟΙΝΟΤΗΤΕΣ（市・共同体等の細区画）、ΕΝΟΡΙΕΣ（街区）、ΔΗΜΟΙ_ΣΥΜΠΛΕΓΜΑΤΑ（市・共同体群）のうち市の名称を採用する。合併後の市名が原典の細区画名称に併記された91区画は、18の新しい市へ所属する構成地区として扱う。これらを合併前の独立自治体として区域階層に並べない。

合併後の市への所属は原典の併記名称を基準とする。市の面とわずかに重なることだけを理由に、併記のない共同体等を新しい市へ所属変更しない。合併後市名には対応する市レイヤーのNAME_GRを使用し、構成地区名にはVIL_NM_Gの併記された細区画名を使用する。それ以外の市・共同体名はVIL_NM_Gに従う。

街区が原典にある区画はその街区を末端として表し、街区のない区画は細区画を末端として保持する。県と合併後の市は上位所属を表し、それらの面を末端区域とは別の画素値で重ねない。共同体群30件はサービス提供の共同体のまとまりであり、合併した市と同一視せず、共同体を置き換える上位自治体としては収録しない。

細区画615件には構成地区と非再編の市・共同体等が含まれ、現在の独立自治体615件を表すものではない。制度上の全街区を網羅するものでもない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `SIMPLE` | 原典の細区画の海岸側外縁を水際線として扱い、その外側の海域を区域に含めない。別の詳細な水際線との一致を保証するものではなく、追加の海岸線資料は使用しない。 |
| 内水面 | `NONE` | 湖沼・河川・貯水池を一律に除外せず、原典の区画面に含まれる水面をその区画として保持する。陸域と水面を明示的に区別する値は持たず、追加の内水面マスクは適用しない。 |

### 1.3 領域・境界

キプロスの原典6県に属する細区画・街区の収録範囲を対象とし、北部を含む区域の外縁、島状部分・飛地・穴は原典に従う。政府の実効支配範囲に限定するマスクや、英国主権基地地域・緩衝地帯を別資料で除外する処理は適用しない。原典にない区域・街区を別年の資料から追加しない。

| 項目 | 扱い | データとしての意味・備考 |
| --- | --- | --- |
| 国境側の境界 | 原典準拠 | 採用する原典区域の境界に従い、別の国境資料による補正は行わない。 |
| 対象領域外 | 背景値 | 採用区域面の外側。 |
| 対象領域内の未割当地点 | 背景値 | 採用面に穴・区域間の隙間がある場合の未割当地点、またはサンプリングで区域が選ばれなかった地点。 |

背景値だけでは領域外、水域、内部の未割当地点を区別できない。区域コードも陸域のみを示す値ではなく、水域の扱いは第1.2節に従う。

区域の収録は領有権、主権、実効支配または法的な境界位置を確定するものではない。微小面積や図形の妥当性判定だけを理由に区域全体・島状部分を除外しない。

格子化により境界のずれや背景画素が生じ得る。区域図の境目を正確な国境線・原典のベクトル境界として使用しない。

### 1.4 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | 細区画はVIL_CCD、街区はQRTR_CCD。VIL_CCDはDIST_CODE × 1,000 + VIL_CODE、QRTR_CCDはVIL_CCD × 100 + QRTR_CODE。原典コードと区域の種類を組み合わせて識別する。 |
| 原典ID値 | remap前のGisRaster値は、街区ではQRTR_CCD、街区のない細区画ではVIL_CCD × 100。細区画を末尾00、街区を原典の末尾2桁で区別する本リリースの整数値であり、合併後自治体の公式コードではない。採用744区域で一意。 |
| 背景値 | `0`。区域コードが割り当てられていない地点を表し、辞書レコードを指さない。対象領域と背景になる条件は第1.3節を参照。 |
| GisWordBookコード | 第3.2節の識別単位に、原典ID値の昇順で1から744まで採番する。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書の葉レコードとnames.csvのwordbook_codeに対応する。全解像度で同じ辞書コード空間を使用する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 第1.3節の対象領域で、末端区域をGisWordBookコードで表す。 |
| GisWordBook | [県名, 市・共同体名, 構成地区名, 街区名]の固定4区域スロット。UTF-8版とUTF-16LE版は同一のコード空間・レコード順序を持つ。 |
| names.csv | `wordbook_code,GRVALUE,DIST_CODE,DIST_NAME,MUNICIPALITY_NAME,COMPONENT_NAME,VIL_CCD,VIL_NM_G,VIL_NM_E,QRTR_CCD,QRTR_NM_G,QRTR_NM_E,LEAF_KIND`の13列。ヘッダーを除くデータ行は末端区域ごとに1行、計744行。 |

GRVALUEは第1.4節の原典ID値。DIST_CODE・VIL_CCD・QRTR_CCDは原典の10進コード文字列。DIST_NAMEは県のDIST_NM_G、MUNICIPALITY_NAME・COMPONENT_NAMEはそれぞれ辞書の区域2・区域3の表示名を保持する。VIL_NM_G・VIL_NM_EおよびQRTR_NM_G・QRTR_NM_Eは原典のギリシャ語・ラテン文字名称を保持する。VIL_CCDとその名称は、街区では所属元の細区画、細区画を末端とする行ではその末端区域を表す。

LEAF_KINDは街区をQUARTER、街区のない細区画をLOCAL_UNITとする。この分類は採用レイヤーの区別であり、新たな行政区分ではない。LOCAL_UNITではQRTR_CCD・QRTR_NM_G・QRTR_NM_Eを空文字列とする。構成地区を置かない場合はCOMPONENT_NAMEを空文字列とする。合併後市の公式コードを推測して追加しない。

codemapは第1.4節の原典ID値とGisWordBookコードの対応であり、製造時だけ使用する。リリースでの照合にはnames.csvを使用する。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | Επαρχία（県）のDIST_NM_G。 | 不可 |
| 区域2 | 合併後の市名、または原典の非再編市・共同体等の名称。 | 不可 |
| 区域3 | 合併後市に属する構成地区名。原典細区画名称の新市名との併記から細区画名を採用する。 | 空文字可（スロットは固定）。該当する構成地区を置かない場合は空文字列。 |
| 区域4 | 原典に収録されたΕνορία（街区）のQRTR_NM_G。 | 空文字可（スロットは固定）。街区のない区画では空文字列。 |

常に4スロットを保持し、空スロットを詰めない。合併後市の街区では`[県名, 市名, 構成地区名, 街区名]`、街区のない構成地区では`[県名, 市名, 構成地区名, ""]`となる。構成地区を置かない市・共同体では区域3を空文字列とし、街区があれば区域4を設定する。最後の非空区域スロットが末端区域である。国名等の共通ノード、原典コードおよび区域種類の属性スロットは含めない。

名称は原典のギリシャ語表記を使用する。原典DBFの文字列幅により街区名称と一部の併記名称の末尾が欠ける場合も、その収録値を表示する。別資料による名称補完、推測による展開、識別用のコード接尾辞の追加は行わない。同名の表示は共有する一方、区域1から区域4までの全名称パスが同じでも、原典ID値が異なる区域には別のGisWordBookコードを割り当てる。同じ原典IDの飛地・複数の図形部分には同じ辞書コードを割り当てる。

同じ表示名であることだけから、同一領域または飛地と判定することはできない。

## 5. 備考・既知の制約

- 原典の市・共同体群レイヤーに20市があることは、北部を含む全島の自治体数を意味しない。
- 原典には県・細区画・街区の境界に微細な差がある。原典コードによる街区の所属は一意だが、その面と親細区画面の完全一致を保証しない。
- 小島・細い区域・飛地は、粗い格子で画素として選ばれない場合がある。辞書のレコード数は、各解像度で出現する画素値の種類数を保証しない。
- GisWordBookコードは本版の辞書レコードを参照する値であり、異なる版の恒久的な区域IDとして使用しない。原典との照合にはnames.csvのコードと区域種類を使用する。
- 原典の基準時点以降の名称・所属・区域形状の変更は反映しない。ギリシャ語名称を保持するためCP932版の辞書は収録しない。
