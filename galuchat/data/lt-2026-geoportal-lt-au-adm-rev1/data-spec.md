# リトアニアINSPIRE行政区域（2026-09-01版）

## 1. 概要

リトアニアのINSPIRE Administrative Unitsを基に、県、自治体、自治体下位の地区を参照できる区域図・名称辞書を収録する。地区を末端区域とし、地区がない自治体および自治体内の地区未所属部分は自治体までの名称で表す。区域図の非ゼロ値は同梱GisWordBookのコードであり、原典コードとの対応はnames.csvで確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | リトアニアINSPIRE行政区域（2026-09-01版） |
| リリースパッケージID | `lt-2026-geoportal-lt-au-adm` |
| 対象地域 | 原典の自治体面が表すリトアニア全域。本土、島状部分、飛地および自治体に含まれる水面を含む。 |
| 対象区域 | 10県・60自治体・533地区。地図の末端は地区または地区未所属部分の自治体。辞書には533地区と60自治体の計593レコードを収録する。 |
| 入力座標系 | ETRS89経緯度（EPSG:4258）。GMLの座標軸順は緯度・経度。 |

### 1.1 対象範囲

原典の2ndOrder（Apskritis、県相当）を区域1、3rdOrder（Savivaldybė、自治体）を区域2、4thOrder（Seniūnija、自治体下位の地区）を区域3とする。所属は原典のupperLevelUnit参照に従う。名称の一致や代表点の位置から親区域を推測しない。

対象範囲の外縁は60自治体の原典面による。各自治体内では、その自治体に所属する地区面の範囲に地区コードを持ち、それ以外は自治体のみのコードを持つ。地区面が親自治体面から微細にはみ出す部分を別自治体へ割り当てず、地区の採用範囲は所属自治体内とする。自治体の全体面とその中の地区を重複した末端区域として表現しない。

下位地区がない6自治体は自治体全体を自治体のみのコードで表す。地区を持つ自治体でも地区面が全域を覆うとは限らず、その未所属部分も同様に扱う。地区未所属部分へ架空の地区名・地区コードを追加せず、区域3は空文字列とする。未所属部分が複数に分かれていても、同じ自治体の未所属部分には同じコードを使用する。

辞書には全533地区に加え、全60自治体について区域3を空文字列としたレコードを保持する。地区未所属の面がない場合や、サンプリングで自治体のみの画素が現れない場合も、この自治体レコードを辞書から取り除かない。辞書593件は、新たな行政区域が593件あることや、各解像度で593種類の画素値が出現することを意味しない。

国の共通ノード、AdministrativeBoundaryの線、ResidenceOfAuthorityの点、別原典の住所点・道路・集落は収録しない。名称は原典のリトアニア語表記を保持し、apskr.、sav.、sen.等の略記やダイアクリティカルマークを変更しない。島状部分、飛地、複数の図形部分および穴は原典に含まれる範囲で扱い、別資料による国境の補正は行わない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `CUSTOM` | 原典の自治体面の外側の外水面は背景とし、面に含まれる水面はその区域として保持する。除外条件は採用自治体面の外側であること。海岸側の外縁は原典に従い、別の海岸線・海域マスクは適用しない。 |
| 内水面 | `NONE` | 湖沼・河川・貯水池・潟を一律に除外せず、自治体面に含まれる水面を区域として保持する。所属地区がある部分は地区、ない部分は自治体までを表す。水面と陸域を明示的に区別する値は持たず、原典の自治体面の穴は背景となる。追加の内水面マスクは適用しない。 |

地区に含まれないことだけを水域の除外条件としない。自治体に含まれるクルシュー潟の地区未所属部分も、自治体までの名称を持つ区域として保持する。

### 1.3 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | 地区と自治体それぞれのnationalCode。INSPIRE識別子はnamespace（LT.RC.ADMVNT）とlocalIdの組であり、localIdはnationalCodeに対応する。地区未所属部分には所属自治体のnationalCodeを使用する。 |
| 原典ID値 | remap前のGisRaster値GRVALUEは、地図上の末端に対応するnationalCodeを10進整数にした正の値。本版では自治体コードが11～94、地区コードが1,201～9,508の欠番を含む値空間で、両者は衝突しない。県コードや国コードLT0は画素値に使用しない。 |
| 背景値 | `0`。採用自治体面の外側、原典の自治体面の穴、サンプリングで区域が選ばれなかった画素。水域や地区未所属を専用に表す値ではない。 |
| GisWordBookコード | 全60自治体レコードと533地区レコードの原典ID値を合わせ、その整数値の昇順で1から593まで採番する。自治体レコードが1～60、地区レコードが61～593。0は辞書レコードを指さない。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書の葉レコードとnames.csvのwordbook_codeに対応する。全解像度で同じ辞書コード空間を使用する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 各地点の所属地区、または地区未所属部分の所属自治体をGisWordBookコードで表す。背景は0。 |
| GisWordBook | `[県名, 自治体名, 地区名]`の固定3スロット。地区未所属部分では地区名を空文字列とする。すべて区域階層であり、属性スロットは設けない。UTF-8版とUTF-16LE版は同じコード空間・レコード順序を持つ。 |
| names.csv | `wordbook_code,GRVALUE,AREA_TYPE,COUNTY_CODE,COUNTY_NAME,MUNICIPALITY_CODE,MUNICIPALITY_NAME,ELDERSHIP_CODE,ELDERSHIP_NAME,LOCAL_ID`の10列。ヘッダーを除くデータ行は自治体レコード60行と地区レコード533行の計593行。 |

GRVALUEは原典ID値、wordbook_codeは最終マップ値。各階層のCODE・NAME列は原典のnationalCode・nameの綴りに対応し、コードは10進コード文字列として保持する。先頭へのゼロ埋め、文字の正規化、他のコード体系への変換は行わない。LOCAL_IDは末端に対応する原典のlocalIdである。

AREA_TYPEは地区レコードではELDERSHIP、自治体レコードではMUNICIPALITY_ONLYとする。この分類は本リリースの表現上の区別であり、新たな行政区分ではない。自治体レコードではELDERSHIP_CODE・ELDERSHIP_NAMEを空文字列とし、自治体コード・名称は実在する原典値を保持する。県と自治体の上位名称は原典内の参照関係に対応する。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | Apskritis（県相当）の原典名称。 | 不可 |
| 区域2 | Savivaldybė（自治体）の原典名称。 | 不可 |
| 区域3 | Seniūnija（地区）の原典名称。 | 可。地区未所属部分では空文字列。 |

常に3スロットを保持し、空スロットを詰めない。地区では`[県名, 自治体名, 地区名]`、地区未所属部分では`[県名, 自治体名, ""]`となり、後者の末端は自治体である。国名等の共通ノード、原典コードおよび末端種類の属性はStringSetに含めない。

区域1・区域2・区域3の全名称パスで辞書レコードを識別する。本版の533地区パスと60自治体パスは合わせて593通りで一意であり、別コードの区域が同じ辞書レコードへ集約されることはない。同じ地区名でも県または自治体が異なれば別レコードとなる。同じ地区の複数の図形部分には同じ地区コード、同じ自治体の複数の地区未所属部分には同じ自治体コードを使用する。

## 5. 備考・既知の制約

* 地区名が空文字列であることは区域がないことを意味しない。自治体までの所属が分かる区域であり、水域専用のレコードでもない。下位地区がない自治体だけでなく、地区を持つ自治体の未所属部分にも現れる。
* 原典の地区面と親自治体面には微細な境界差がある。本製品の外縁と所属自治体は自治体面を基準とし、地区は所属自治体内の範囲で表すため、地区原典の全頂点を無変更で再現する製品ではない。
* 原典のAnykščių sen.（nationalCode 3408）にはGEOSのRing Self-intersection判定があるが、空・ゼロ面積の区域ではない。この判定のみを理由に区域全体・島状部分を除外する仕様とはしない。地区や地区未所属部分を微小面積だけで間引く仕様も設けない。
* 区域図は原典の区域を格子化したものであり、境界付近では元のベクトル境界と判定が一致しない場合がある。小島・細い区域・飛地は粗い格子で画素化されない場合がある。辞書件数は、各解像度に出現する画素値の種類数を保証しない。
* 区域コードだけから水面と陸域を区別できず、背景値0だけから水域や外国を判定することもできない。海岸側の外縁は原典に従うが、別の詳細な水際線との一致を保証しない。
* 原典との照合にはnames.csvの階層別コードと末端種類を使用する。GisWordBookコードは本版の辞書レコードを参照する値であり、異なる版の恒久的な区域IDとして使用しない。
* 名称・所属・区域形状は2026-09-01版の採用原典に依存し、その後の変更は反映しない。原典名称の文字を保持するためCP932版の辞書は収録しない。本区域図は法的な境界位置や土地の権利を確定するものではない。
