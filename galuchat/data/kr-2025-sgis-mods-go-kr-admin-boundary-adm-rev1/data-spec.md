# 国家データ処 SGIS行政区域境界（2025年第2四半期）

## 1. 概要

国家データ処のSGIS行政区域境界を、行政洞ごとの区域図と、市・道／市・郡・区／行政洞の名称辞書として収録する。区域図の非ゼロ値は同梱GisWordBookのコードであり、原典の行政区域コードとの対応は`names.csv`で確認できる。同じ公開ZIPに含まれる人口等の統計値は、この地図製品には収録しない。

| 項目 | 内容 |
| --- | --- |
| データセット名 | 国家データ処 SGIS行政区域境界（2025年第2四半期） |
| リリースパッケージID | `kr-2025-sgis-mods-go-kr-admin-boundary-adm` |
| 対象地域 | 原典SGIS境界に収録された大韓民国の地域。島嶼を含む。 |
| 対象区域 | 行政洞3,559区域。名称階層には市・道17区域、市・郡・区252区域を使用する。 |
| 入力座標系 | KGD2002 / Unified CS（UTM-K、EPSG:5179）。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | 原典のEPSG:5179座標をPROJによりEPSG:4326へ再投影する。 |
| 原典版・基準時点 | 2025年第2四半期境界、`BASE_DATE=20250630`（2025-06-30）。 |

### 1.1 対象範囲

原典の`bnd_dong_00_2025_2Q`にある行政洞3,559区域を採用し、市・道レイヤと市・郡・区レイヤから名称上の親区域を対応付ける。すべての行政洞には原典コードの接頭辞で対応する両親区域がある。

最下位区域は行政洞であり、法定洞ではない。市・道や市・郡・区を独立した画素値とする別製品、人口・住宅・事業所などの統計値、および原典に含まれない区域は収録しない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | CUSTOM | 採用した行政洞面の外側の外水面だけを除外し、面内の沿岸水域は区域として保持する。別の海岸線マスクは適用しない。測量精度を保証するものではない。 |
| 内水面 | NONE | 湖沼・河川を一律に除外せず、原典の行政洞面に含まれる水域はその区域として保持する。別の内水面マスクは適用しない。 |

### 1.3 領域・境界

韓国の原典行政洞3,559区域の収録範囲を対象とする。同一コードに属する離れたポリゴン・島嶼も採用し、同一区域として扱う。原典にない領域は補完しない。

| 項目 | 扱い | データとしての意味・備考 |
| --- | --- | --- |
| 国境側の境界 | 原典準拠 | 採用する原典区域の境界に従い、別の国境資料による補正は行わない。 |
| 対象領域外 | 背景値 | 採用区域面の外側。 |
| 対象領域内の未割当地点 | 背景値 | 採用面に穴・区域間の隙間がある場合の未割当地点、またはサンプリングで区域が選ばれなかった地点。 |

背景値だけでは領域外、水域、内部の未割当地点を区別できない。区域コードも陸域のみを示す値ではなく、水域の扱いは第1.2節に従う。

格子化により境界のずれや背景画素が生じ得る。区域図の境目を正確な国境線・原典のベクトル境界として使用しない。

### 1.4 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | 8桁の行政洞コード`ADM_CD`。先頭5桁が`SIGUNGU_CD`、先頭2桁が`SIDO_CD`に一致する。対応表では文字列として保持する。 |
| 原典ID値 | remap前のGisRaster値は`ADM_CD`を10進整数化した正の値。同版の3,559区域に対して一意である。 |
| 背景値 | `0`。区域コードが割り当てられていない地点を表し、辞書レコードを指さない。対象領域と背景になる条件は第1.3節を参照。 |
| GisWordBookコード | 第3.2節の名称パスに、`ADM_CD`昇順で1から採番する。コード範囲は1～3,559。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書と`names.csv`の`wordbook_code`に対応する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 第1.3節の対象領域で、行政洞をGisWordBookコードで表す。 |
| GisWordBook | `[SIDO_NM, SIGUNGU_NM, ADM_NM]`の固定3スロット。両文字コード版は同一のコードと名称パスを持つ。 |
| names.csv | `wordbook_code,GRVALUE,SIDO_CD,SIDO_NM,SIGUNGU_CD,SIGUNGU_NM,ADM_CD,ADM_NM`の8列。行政洞ごとに1行、計3,559行。 |
| codemap | 製造時に原典ID値をGisWordBookコードへ変換する対応表。リリースZIPには含めない。 |

`names.csv`の`GRVALUE`は原典ID値、`wordbook_code`は最終マップ値である。`SIDO_CD`、`SIGUNGU_CD`、`ADM_CD`は原典コードを文字列として保持する。名称列は原典の韓国語表記を保持する。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | `SIDO_NM`が表す市・道名。 | 不可。 |
| 区域2 | `SIGUNGU_NM`が表す市・郡・区名。 | 不可。 |
| 区域3 | `ADM_NM`が表す行政洞名。 | 不可。 |

国名の共通ノードと原典コードはStringSetに含めない。世宗特別自治市にも原典の中間層`세종시`を区域2として保持し、スロットを省略しない。同名の市・郡・区や行政洞は3スロット全体で識別し、最下位名だけが同じ区域を集約しない。本版では3,559区域の全名称パスに重複がない。個別の原典コードは`names.csv`で確認する。

## 5. 備考・既知の制約

- 原典の基準時点以降の行政改編は反映しない。
- 小島・細い区域・飛地は、粗い格子で画素として選ばれない場合がある。
- GisWordBookコードは本版の名称パスに対する値で、将来版まで固定される行政コードではない。異なる版の区域との照合には`names.csv`の原典コードを用いる。
- 原典の韓国語名称を保持するため、CP932版の辞書は収録しない。
