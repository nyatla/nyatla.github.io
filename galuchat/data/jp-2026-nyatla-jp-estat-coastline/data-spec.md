# e-Stat海岸線反映区域データ

この文書は本リリースのデータの**外部仕様**を記述する。製造工程や中間ファイル名は規定しない。出典・利用条件は[NOTICE.md](NOTICE.md)を参照する。

## 1. 概要

本データセットは、令和2年国勢調査の町丁・字等境界データに、N03-2026の行政区域が示す海岸線を反映した区域地図である。N03の区域外にはe-Statの小地区値を残さない。N03の区域内ではe-Statの小地区値を優先し、e-Statで区域が定義されていない地点はN03の行政区域代表値で補う。

| 項目 | 内容 |
| --- | --- |
| データセット名 | e-Stat海岸線反映区域データ |
| リリースパッケージID | `jp-2026-nyatla-jp-estat-coastline` |
| 対象地域 | 日本全国 |
| 対象区域 | N03-2026の行政区域ラスタで非0となる範囲。e-Statの小地区またはN03の行政区域代表値で表す。 |
| 入力座標系 | N03・e-StatともJGD2011地理座標（EPSG:6668） |
| 出力座標系 | WGS 84互換の緯度経度格子 |
| 座標変換 | 入力のJGD2011座標値を再投影・測地系変換せず、WGS 84互換の座標値として格納する。 |
| 原典版・基準時点 | N03 `N03-20260101`（2026年1月1日時点）、e-Stat `A002005212020`（2020年国勢調査） |

### 1.1 対象範囲

47都道府県の町丁・字等境界を対象とし、最終的な地図範囲はN03-2026の行政区域ラスタに従う。島嶼・飛地はN03の収録範囲に含まれる限り対象となる。N03で背景となる地点には、e-Statの値があっても区域を割り当てない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `CUSTOM` | e-Stat原典に含まれる外水面の指定区域は小地区として採用しない。さらにN03の行政区域ラスタで背景となる地点は背景値`0`とする。N03が非0の地点は、e-Statが採用されなければN03の行政区域代表値になり得る。 |
| 内水面 | `NONE` | 水面だけを対象とする追加の切り抜きは行わない。N03の区域判定とe-Statの小地区値に従う。 |

海岸線の「反映」は、N03で背景となる地点へe-Statの区域を延ばさず、e-Stat由来の指定外水面区域を小地区として採用しないことを指す。外水面の指定区域を無条件に背景値`0`へ置き換える意味ではない。

### 1.3 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | e-Statの`PREF,CITY,S_AREA`による地区コードと、N03の`N03_007`による行政区域コード。地区コードは個別ポリゴンの一意IDではない。 |
| 原典ID値 | 各原典の区域コードを数値化した値。最終地図には直接格納しない。 |
| 背景値 | `0`。N03の行政区域外または未定義領域を示し、GisWordBookの項目を指さない。 |
| GisWordBookコード | 統合GisWordBookの葉レコードを新規採番した`x_district_id2 + 1`。 |
| マップコード | 最終WGSMapSetの非0画素値。対応する統合GisWordBookの葉レコードを指す。 |

同名・同一地区コードの複数ポリゴンがあり得る。マップコードは名称階層の項目を指し、個別ポリゴンを識別するものではない。

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 各地点に統合GisWordBookコードまたは背景値`0`を格納する。N03区域内のe-Stat小地区を優先し、未定義部分はN03行政区域代表値とする。 |
| GisWordBook | N03の行政階層とe-Statの小地区階層を統合した固定6階層の名称辞書。 |

### 3.2 StringSet

GisWordBookの各レコードは次の6スロットの固定長パスを持つ。国名などの共通ノードは含めない。

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | 都道府県 | 不可 |
| 区域2 | 郡 | 可。存在しない場合は空文字列。 |
| 区域3 | 市区町村 | 不可 |
| 区域4 | 政令指定都市の行政区 | 可。存在しない場合は空文字列。 |
| 区域5 | e-Stat小地区 | 可。行政区域代表値では空文字列。 |
| 区域6 | e-Stat下位地区 | 可。存在しない場合は空文字列。 |

区域5・6がともに空文字列の項目はN03の行政区域代表値である。e-Statの小地区はN03の行政階層の下に配置する。同じ表示名が複数あっても、全階層の組合せとコードで区別する。3種類のGisWordBookは文字エンコーディングだけが異なり、レコード順序、コードおよび論理内容は同一である。

### 3.3 画素値の採用規則

N03とe-Statの値を同じ統合GisWordBookのコード空間で解釈したとき、各地点の最終値は次のようになる。e-Statの「値あり」は、第1.2節で採用しないとした外水面の指定区域を除いた値を指す。

| N03 | e-Stat | 最終画素値 |
| --- | --- | --- |
| 背景値`0` | 任意 | 背景値`0` |
| 非0 | 値なし | N03の行政区域代表値 |
| 非0 | 値あり | e-Statの小地区値 |

## 4. WGSMapSet生成パラメータ

### gis-estat-integrated-grid-8192-10000.wgsmapset.glc

#### サンプリング方式

| 項目 | 値 | 備考 |
| --- | --- | --- |
| sampling | `MAX_AREA` | e-Stat区域のセル内最大面積を採用する。N03側の値は上流N03パッケージの仕様に従う。 |
| minimum rate | `0.01` | e-Stat区域の最小採用率。 |

#### WGSMapSet格納方式

| 項目 | 値 | 備考 |
| --- | --- | --- |
| palette / block format / 圧縮 | `auto` / `all` / `lzss` | 最終WGSMapの格納設定。 |
| unit-inv | `10000` | サンプリング単位は1/10000度。 |
| SHP grid cell-size | `8192` | 対応するShapefile分割格子のセルサイズ。 |
| block-size | `512` | WGSMapSetブロックサイズ。 |

## 5. 備考・既知の制約

* e-Statの町丁・字等境界は統計調査用で、一般的な行政区域や住居表示の境界と必ずしも一致しない。N03とe-Statの基準時点も異なる。
* 海岸線はN03の行政区域ラスタを基準とする。画素単位の境界は、原典のベクトル境界と完全には一致しない場合がある。
