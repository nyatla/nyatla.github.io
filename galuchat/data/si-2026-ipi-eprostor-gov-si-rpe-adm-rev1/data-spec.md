# スロベニアRPE集落区域（2026-09-27配布版）

## 1. 概要

スロベニア測量地図局（GURS）のRegister prostorskih enot（RPE）を基に、自治体と集落の2段階を参照できる区域図・名称辞書を収録する。末端区域はNaselje（集落区域）とし、建物点や市街地だけを表すものではない。区域図の非ゼロ値は同梱GisWordBookのコードであり、原典識別子との対応はnames.csvで確認できる。

| 項目 | 内容 |
| --- | --- |
| データセット名 | スロベニアRPE集落区域（2026-09-27配布版） |
| リリースパッケージID | `si-2026-ipi-eprostor-gov-si-rpe-adm` |
| 対象地域 | 原典のNaselje面が表すスロベニア全域。島状部分、飛地および原典区域に含まれる水面を含む。 |
| 対象区域 | Naseljeの6,035区域。上位名称はObčina（自治体）の212区域。 |
| 入力座標系 | Slovenia 1996 / Slovene National Grid（EPSG:3794）。 |
| 出力座標系 | WGS 84経緯度（EPSG:4326）。 |
| 座標変換 | EPSG:3794からEPSG:4326へ再投影・測地系変換する。 |
| 原典版・基準時点 | RPE_SLO_PROSTORSKE_ENOTE_20260927.zipの2026-09-27配布版。ファイル名の版識別日であり、各区域のDATUM_SYSとは区別する。全区域共通の法的な行政界基準日とは断定しない。 |

### 1.1 対象範囲

原典のnaselja全区域を末端区域として採用する。区域1はobcineの自治体名、区域2はnaseljaの集落名とし、所属はEID_OBCINAに従う。自治体の面を別の画素値として重ねない。

行政単位（upravna enota）、統計地域、凝集地域、選挙区・投票区、学校区、郵便区、地区・村等の共同体は名称階層と区域地図に含めない。行政単位と自治体は一律の親子関係ではないため、行政単位→自治体→集落の階層へ読み替えない。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `CUSTOM` | 採用する原典集落面の外側の外水面だけを除外し、面内の水面はその集落の区域として保持する。水際形状は原典に従い、別の海岸線・海域マスクは適用しない。 |
| 内水面 | `NONE` | 湖沼・河川を一律に除外せず、原典の集落面に含まれる水面はその集落の区域として保持する。水面と陸域を明示的に区別する値は持たず、追加の内水面マスクは適用しない。 |

### 1.3 領域・境界

スロベニアの原典naselja全区域の収録範囲を対象とし、飛地・全図形部分・穴を原典どおり保持する。

| 項目 | 扱い | データとしての意味・備考 |
| --- | --- | --- |
| 国境側の境界 | 原典準拠 | 採用する原典区域の境界に従い、別の国境資料による補正は行わない。 |
| 対象領域外 | 背景値 | 採用区域面の外側。 |
| 対象領域内の未割当地点 | 背景値 | 採用面に穴・区域間の隙間がある場合の未割当地点、またはサンプリングで区域が選ばれなかった地点。 |

背景値だけでは領域外、水域、内部の未割当地点を区別できない。区域コードも陸域のみを示す値ではなく、水域の扱いは第1.2節に従う。

格子化により境界のずれや背景画素が生じ得る。区域図の境目を正確な国境線・原典のベクトル境界として使用しない。

### 1.4 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | NaseljeのEID_NASELJ。18桁の識別子をnames.csvで文字列として保持する。自治体内のSIFRAおよび自治体と集落の複合コードSESTAVLJENとは別の識別子。 |
| 原典ID値 | remap前のGisRaster値はSESTAVLJENの正の整数値。自治体SIFRA × 1000 + 集落SIFRAに一致し、本版の値域は1,001～213,001。集落SIFRAだけは全国で一意ではなく、18桁EIDをラスタ値としては使用しない。 |
| 背景値 | `0`。区域コードが割り当てられていない地点を表し、辞書レコードを指さない。対象領域と背景になる条件は第1.3節を参照。 |
| GisWordBookコード | 原典ID値の昇順に1から6,035まで採番する。 |
| マップコード | 原典ID値をGisWordBookコードへremapした値。非ゼロ値は同梱辞書の葉レコードとnames.csvのwordbook_codeに対応する。全解像度で同じ辞書コード空間を使用する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 第1.3節の対象領域で、末端区域をGisWordBookコードで表す。 |
| GisWordBook | [自治体名, 集落名]の固定2スロット。すべて区域階層であり、属性スロットは設けない。UTF-8版とUTF-16LE版は同一のコード空間・レコード順序を持つ。 |
| names.csv | `wordbook_code,GRVALUE,OBCINA_EID,OBCINA_CODE,OBCINA_NAME,OBCINA_NAME_DJ,NASELJE_EID,NASELJE_CODE,NASELJE_NAME,NASELJE_NAME_DJ`の10列。ヘッダーを除くデータ行は末端区域ごとに1行、計6,035行。 |

GRVALUEはSESTAVLJENに対応する原典ID値。OBCINA_EID・NASELJE_EIDは原典の18桁EIDを文字列として保持する。OBCINA_CODEは自治体のSIFRA、NASELJE_CODEは自治体内の集落SIFRAの10進表記であり、NASELJE_CODE単独では全国一意の識別子ではない。NAMEはNAZIV、NAME_DJはNAZIV_DJを保持し、別言語名称の欠落は空文字列とする。

### 3.2 StringSet

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | Občina（自治体）の主名称NAZIV。 | 不可 |
| 区域2 | Naselje（集落）の主名称NAZIV。 | 不可 |

国名等の共通ノード、空スロットおよび属性スロットは含めない。辞書レコードは区域1・区域2の組で識別し、本版の6,035集落では異なる原典IDがこの組を共有しない。同じEID_NASELJの飛地・複数の図形部分には同じ辞書コードを割り当てる。

別言語名称は主名称と連結・置換せず、その有無によって辞書コード空間を分割しない。

## 5. 備考・既知の制約

- 18桁EIDを表計算ソフト等で読み込む場合、浮動小数点への自動変換による桁落ちに注意する。
- 小島・細い区域・飛地は、粗い格子で画素として選ばれない場合がある。辞書のレコード数は、各解像度で出現する画素値の種類数を保証しない。
- GisWordBookコードは本版の辞書レコードを参照する値であり、異なる版の恒久的な区域IDとして使用しない。原典との照合にはnames.csvの識別子を用いる。
- 原典名称の文字を保持するためCP932版の辞書は収録しない。名称・区域は採用した原典版に依存し、その後の変更は反映しない。本区域図は法的な境界位置や土地の権利を確定するものではない。
